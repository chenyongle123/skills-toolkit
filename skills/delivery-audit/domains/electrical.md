## 本领域高频错误（速查，详见上述领域文件）

| 原编号 | 模式 | 一句话检测 |
|---|---|---|
| B1 | 跨电压等级阻抗未归算 | 不同电压侧的阻抗运算前做电压比归算了吗？ |
| B2 | 单位不匹配 | kV/V、MVA/kVA 混用了吗？ |
| B3 | 基准值不一致 | 同一计算链的 Sb、Ub 统一吗？ |
| C1 | 双重变比 | CT/PT 变比在公式里出现 >1 次了吗？ |
| C2 | 重复单位换算 | 参数已经是目标单位，又换算了一次吗？ |
| D1 | 定值-校核同源 ★ | 灵敏度校验与定值用了同一个电流吗？（应分别取小/大方式）|
| D2 | 循环依赖 | 公式链有环吗？ |
| E1 | 级差不满足 | 下级时限 + Δt ≤ 上级时限？ |
| F1 | 必填参数缺失 | 规范要求的参数齐了吗？ |
| F2 | 模态覆盖不全 | 充电/放电、最大/最小方式都算了吗？ |
| F3 | 边界条件未处理 | 零/负/空输入处理了吗？ |
| G1 | 无依据公式 | 每个系数的规范出处找到了吗？ |
| G2 | 规范引用错误 | 保护类型-电压等级-规范 三元组匹配吗？ |

---

## 关键口诀（血泪教训）

1. **躲故障取大方式，灵敏度取小方式**（D1，2026-10-10 E6）
2. **缺参必须阻断，不得回退算例默认值**（F1，2026-10-10 E9）
3. **所有"通过"必须披露实际裕度；约束倒挂/空集必须报 WARN**（F3，2026-10-10 E7）
4. **涉及"哪一侧"的参数，先确认安装位置，再确认基准量取自哪一侧**（B3，2026-10-10 连带发现）
5. **看似相消的项，必须独立推导验证，不得目测**（2026-10-10 E1）
6. **参数名像物理量、值是"整数字"、旁边有算例注释 = 算例污染高危信号**（G1/G2，E2/E3）
