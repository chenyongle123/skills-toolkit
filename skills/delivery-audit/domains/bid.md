# 领域清单：投标 / 标书编制

> `delivery-audit` 纵向领域清单。做招标文件审查、投标响应策划、合规检查、技术标写作、排版导出时追加本清单。
>
> **配套技能链**：`tender-document-review`（⓪ 招标解读）→ `bid-response-plan`（① 策划）→
> `bid-technical-proposal`（③ 写作）→ `bid-compliance-check`（② 检查）→ `bid-docx-export`（④ 导出）。
> 本清单覆盖全链共性问题，**不替代各技能自带的 references 清单**。
>
> **诚实声明（2026-10-31 建域）**：下表错误模式来自两类可追溯来源——
> ① 本套件各技能 SKILL.md / references 中**已白纸黑字写明**的禁令与实测反馈；
> ②《趴一趴市面上智能标书软件》一文点名的行业通病（已由本套件实测核对）。
> **本文件不是真实废标通报库**——真实废标案例、本单位历史丢分项请在文末「留白区」由使用者补充，
> 未补充前**不得声称已有案例库**。

## M7 可机检断言（供 `scan_doc.py --markers` 使用）

配套标记文件：`domains/bid-regression-markers.json`。

用法（审查投标类交付文档时）：

```
python scripts/scan_doc.py <交付文档>.md --markers domains/bid-regression-markers.json
```

断言只覆盖**可字符串判定**的部分；BID-01/02/03/06 等需语义判断的项**不在 M7 内**，
仍由各技能脚本（`check_consistency.py` / `verify_docx.py` / `check_similarity.py`）负责——
**不得因为 M7 通过就认为这些项已查**。
