> 在跑完横向四段闸门之后，追加本清单。

## L-A 类：引用现行性（最容易犯）★

### L-A1 — 引用已废止文件 ★ 真实案例
**症状**：引用了已被取代的法律/司法解释。

**真实案例（2026-10-10）**：
- ✗ 引用《合同法》第X条 —— **《合同法》已于 2021.1.1 废止**，由《民法典》取代
- ✗ 引用《合同法解释（二）》第29条 —— **已于 2021.1.1 废止**
- ✗ 引用原《建设工程施工合同司法解释》（法释〔2004〕14号）—— 已整合为施工解释一

**检测动作**：
1. 列出报告中所有被引用的法律文件（法律、司法解释、规章、标准）；
2. 逐个核对**是否现行有效**（有无被取代、被废止、被整合）；
3. 特别警惕：**规则内容还在，但载体文件已换**（如"违约金超损失30%"规则从
   合同法解释二 → 合同编通则解释）。

**已废止清单（禁引）**：
| 禁引文件 | 废止时间 | 替代 |
|---|---|---|
| 《合同法》 | 2021.1.1 | 《民法典》合同编 |
| 《合同法解释一》《合同法解释二》 | 2021.1.1 | 合同编通则解释（法释〔2023〕13号）|
| 施工合同司法解释（法释〔2004〕14号） | 2021.1.1 | 施工解释一（法释〔2020〕25号）|
| 施工合同解释（二）（法释〔2018〕20号） | 2021.1.1 | 施工解释一（法释〔2020〕25号）|

## L-B 类：文号与条款号准确性 ★

### L-B1 — 文号张冠李戴
**症状**：文号记错、编号混淆（如把 25 号记成其他号）。
**真实核对清单（已验证）**：
| 文件 | 正确文号 | 施行日 |
|---|---|---|
| 施工解释一 | **法释〔2020〕25号** | 2021.1.1 |
| 合同编通则解释 | **法释〔2023〕13号** | 2023.12.5 |
| 买卖合同解释 | **法释〔2020〕17号** | — |
| **背靠背批复**（大型企业与中小企业以第三方支付款项为付款前提条款效力问题的批复）| **法释〔2024〕11号** | **2024.8.27**（经官网公报核验）|
| 建设工程质量保证金管理办法 | **建质〔2017〕138号** | 2017.6.20印发（经中国政府网核验）|

**检测动作**：每个文号必须能说出出处（官方公布页/权威汇编），说不清 = UNVERIFIED。

### L-B2 — 条款号与内容不匹配
**症状**：条号对，但内容说错了（引"第65条"却描述成第64条的内容）。
**检测动作**：**不能只核对条号存在**（违背 L2 存在≠准确），必须核对
**"这个条号对应的具体内容"** 是否与你描述的一致。

**关键条款内容核对表（本领域高频引用）**：
| 条款 | 内容要点 |
|---|---|
| 民法典 第585条 | 违约金过分高于损失可减少 |
| 合同编通则解释 第64条 | 违约方主张调整需举证；"约定不得调整"无效 |
| 合同编通则解释 第65条 | **超过损失30%** 一般认定"过分高于"；是"损失"的30%，非合同总额 |
| 合同编通则解释 第9条 | 格式条款认定（示范文本/约定不属格式条款的抗辩**不予支持**）|
| 合同编通则解释 第14条 | 多份合同与虚假意思表示 |
| 施工解释一 第41条 | 优先受偿权行使期限最长18个月 |
| 施工解释一 第42条 | 放弃优先受偿权的效力 |
| 施工解释一 第43条 | 实际施工人起诉规则 |
| 买卖合同解释 第18条 | 逾期付款损失：LPR 加计 30-50% |
| **背靠背批复 第1条** | 大型企业↔中小企业"以收到第三方款项为付款前提"约定**无效**（《民法典》第153条第1款）；第2条：无效后利息无约定按一年期LPR |

## L-C 类：口径精确性 ★

### L-C1 — 比例/口径张冠李戴 ★ 真实案例
**症状**：把"损失的比例"说成"合同额的比例"。

**真实案例（2026-10-10）**：
- ✗ "违约金超过合同金额的30%" —— **错**
- ✗ "违约金不得超过损失/合同的130%" —— **口径混乱**
- ✓ "**超过造成的损失的30%**，一般可认定'过分高于'"（合同编通则解释第65条）
- ✓ 且须注明：30% 只是**参考标尺，非法定上限**；是**损失**的30%，非合同总额

**检测动作**：凡涉及比例，必须同时落实三件事：
① 分子是谁的量？② 分母是谁的量？③ 是法定上限还是参考标准？

### L-C2 — 法律不存在的规定（臆造）
**症状**：编造不存在的法定比例/期限。
**真实案例**：✗ "中国法规定违约金不得超过合同金额的20%" —— **中国法无此统一上限**。
**检测动作**：任何"法律规定……不得超过/必须……"的断言，必须能指到具体条文；指不到 = 删除或标 UNVERIFIED。

## L-D 类：立场与适用性

### L-D1 — 立场未确认
**症状**：未确认用户是甲方还是乙方就下结论。同一句条款对不同立场意义相反。
**检测动作**：立场不明 → **先问再答**，不得默认。

### L-D2 — 效力未分析（把无效条款当风险报）
**症状**：把"本身无效的条款"报成"对我方不利，建议谈判"。
**真实案例**：放弃优先受偿权的约定，若损害建筑工人利益，依施工解释一第42条不予支持
—— 正确提示是"该条可能无效，不必过度担心，但别依赖它"，而非"建议删除"。
**检测动作**：对效力存疑的条款，给**效力分析**，拿不准标"待法律核实"。

### L-D3 — 行业惯例当绝对标准
**症状**：不区分行业/地域/主体性质，直接说"这不常见"。
**检测动作**：先看立场、主体性质（大企业/中小企业）、行业惯例，再下"是否异常"的结论。

## L-E 类：完整性

### L-E1 — 漏读附件与专用条款
**症状**：只读主体，漏了技术协议、工程量清单、补充协议、附件。
**检测动作**：明确列出**读了哪些部分、没读哪些部分**；读不了的（扫描件）显式声明。

### L-E2 — 缺"该写没写的"条款
**症状**：只报"写了的不利条款"，不报"缺失的关键条款"。
**检测动作**：对照必备条款清单，缺失项标"缺失："并给出法律默认后果。

## 交付时的法律类自检清单

```
□ L-A1 所有引用文件均为现行有效（无《合同法》《合同法解释》等已废止）
□ L-B1 文号准确（25号/13号/17号）
□ L-B2 条款号↔内容匹配
□ L-C1 比例口径精确（是"损失的30%"，非合同总额）
□ L-C2 无臆造法律（每个"法律规定"都能指到条文）
□ L-D1 立场已确认
□ L-D2 效力存疑条款已作效力分析
□ L-D3 未把行业惯例当绝对标准
□ L-E1 已声明读取范围（含/不含附件）
□ L-E2 缺失条款已列出
```

**核验渠道**（必须能给出）：
- 国家法律法规数据库 flk.npc.gov.cn
- 最高人民法院官网 / 中国裁判文书网
- 住建部官网
- 最高人民法院数字图书馆
