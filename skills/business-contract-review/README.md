# business-contract-review（中国法商务合同审核）

对中文商务合同做**条款级审查**：识别风险、按红黄绿分级、给出可直接插入合同的修改文本（redline）与谈判策略。以中国法（《民法典》及相关部门法）为基础，**不构成法律意见**，决策前须由具备资格的法律专业人士复核。

## 输入

| 输入 | 必填 | 说明 |
|---|---|---|
| 合同文本/文件 | 是 | PDF / DOCX / WPS / 扫描件（OCR）/ 粘贴文本；**必须完整读取全文**（附件、专用条款、补充协议往往风险最大） |
| 我方立场 | 是 | 发包人/总包/分包/采购方/供货方/委托方/受托方/招标人/代理机构/劳务发包人或承包人——立场搞反，红黄绿全部颠倒 |
| 合同类型 | 是 | 工程施工/EPC、物资设备采购、技术服务/咨询、招标代理/劳务、**新能源项目（风电/光伏/储能）**、**投资侧交易（股权/合作开发/对赌回购/EMC）**（六类路由；新能源 EPC = `01`+`08` 双跑，新能源合作开发 = `08`+`09` 双跑） |
| 审查焦点 / 交易背景 | 可选 | 特别关注点、金额量级、是否招投标项目、是否对方格式文本 |

## 产出

- **条款级审查报告**：逐条风险识别 + 红黄绿三级分级 + 定位（条款号/出处）
- **redline 修改建议**：可直接插入合同的修改文本
- **谈判策略**：分级事项的让步/坚持排序
- **待澄清清单**：解释顺序缺失、关键参数留白等

## 流程（9 步）

接收合同 → 收集上下文（立场/类型/焦点）→ 识别成套文件与解释顺序 → **六类路由**（专用清单，可叠加）→ 通用条款叠加审查 → 红黄绿分级 → redline（含**法定/裁判口径/商业建议**性质标注）与谈判策略 → 成稿 → **第九步交付前收口自检（法律类 13 项）**。

## 关卡

- **立场关卡**：我方立场未确认时**不停等**——按 v1.1 规则输出**甲乙双栏对照**，标记"双向提示"，确认后收敛为单侧分级
- **核验关卡（v1.1 新增）**：每一条法律/司法解释引用必须经至少一次权威信源检索；**凭记忆落下的条号视为未核验**，须删除或改标"待核实"
- **时间边界关卡（v1.1 新增）**：有时间效力的规则（如公司法第88条第1款仅适用 2024-07-01 后）必须先确认案涉行为发生时点再适用
- **第九步自检**：自带法律类 13 项交付前检查，不依赖外部技能；环境中存在 `delivery-audit` 且用户点名时可加载其 `domains/legal.md` 加大审查力度
