# 技术服务 / 咨询合同专用检查清单

> 适用：技术服务合同、技术咨询合同、工程设计合同、勘察合同、管理咨询、信息化服务、运维服务、检测检验服务、软件实施/开发服务合同。
> 主要法律依据：
> - 《民法典》技术合同章（第843-887条，尤其第859、860条）、承揽合同章（第770-787条）、委托合同章（第919-936条，尤其第933条）
> - **《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》**（法释〔2023〕13号，下称"**合同编通则解释**"）：合同解释规则（第1条）、违约金调减规则（第64-65条）
> - 《著作权法》《计算机软件保护条例》《个人信息保护法》
> 立场差异提示：委托方（甲方）vs 受托方/服务方（乙方）。**成果标准、验收口径、知识产权归属、保密**是核心对立点。
> 定性提示：先判断是"技术服务"还是"技术开发"——**开发类成果归属与风险承担规则不同**（《民法典》第859、860条）。

---

## 一、服务范围与成果定义

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **服务范围**是否具体、可界定（避免"提供相关技术支持"等模糊表述）| 🔴 | 范围不清 = 无限追加工作 or 成果不足的争议根源 |
| **交付成果**清单及形式（报告/图纸/软件/数据/成果文件）| 🟡 | 成果形态决定验收标准与著作权归属 |
| 服务方式：驻场 / 远程 / 定期 / 一次性 | 🟢/🟡 | 影响成本与知识产权 |
| **工作量/服务量**是否量化（人天、月、次）| 🟡 | 无量化则变更、加量无从计价 |
| 是否明确**不包含**的事项（排除范围）| 🟡 | 防止范围蔓延（scope creep）|
| 甲方需提供的资料、配合、场地、接口人 | 🟡 | 甲方配合义务缺失，乙方可据以顺延/免责 |

---

## 二、服务期限与进度

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 服务起止时间、里程碑节点 | 🟡 | 里程碑不清则进度款无据 |
| **进度款**与里程碑的对应关系 | 🟡 | 建议每节点绑定可验证的交付物 |
| 期限顺延的申请与确认 | 🟡 | 甲方拖延配合应可顺延（乙方立场）|
| 是否约定**暂停/中止**及费用处理 | 🟢/🟡 | 长期服务合同需评估 |

---

## 三、验收与成果标准（核心）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 验收标准是否**客观、可衡量** | 🔴 | "满足甲方要求""甲方满意"等主观标准对乙方是重大风险 |
| 验收程序：提交—评审—反馈—修改—确认 | 🟡 | 明确修改次数上限与超次处理（乙方立场务必设上限）|
| **验收期限**与逾期不反馈视为通过的规则 | 🟡 | 乙方立场应力争"逾期视为验收合格"；甲方立场应明确答复义务 |
| 成果不达标时的处理：返工 / 减价 / 解除 | 🟡 | 明确三级处理机制及费用承担 |
| 是否约定**第三方评审/专家验收** | 🟢/🟡 | 客观性强，但需明确费用与时限 |
| 验收合格不免除**质量责任**的范围 | 🟢 | 一般条款 |

---

## 四、价款、付款与税务

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 计价方式：总价包干 / 人天单价 / 成本加酬金 | 🟡 | 决定变更与超支风险归属 |
| 付款节点与比例（预付/进度/验收/尾款）| 🟡 | 服务方力争预付与进度款；委托方力争验收后付款 |
| 是否含税、发票类型、开票时点 | 🟡 | 影响税负与现金流 |
| **差旅、驻场、第三方工具/采购**费用是否另计 | 🟢/🟡 | 隐性成本，需明确 |
| 变更（change order）的计价规则 | 🟡 | 缺失则变更无价，易扯皮 |
| 逾期付款违约金 | 🟡 | 服务方立场需明确 |

---

## 五、知识产权（技术服务合同的高频重灾区）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 成果著作权/专利权**归属**是否明确 | 🔴 | 《民法典》第859条：委托开发完成的发明创造，除另有约定外申请专利的权利归研究开发人（受托人）；**未约定时的默认规则可能出乎双方意料，必须明确** |
| 是否区分**背景知识产权**（各自原有）与**前景成果**（本次产出）| 🔴 | 未区分易导致一方原有技术被无偿归属对方 |
| 委托方对成果的**使用权范围**（是否含二次开发、转授权）| 🟡 | 影响成果的商业化 |
| 乙方是否有权将成果**用于其他项目/复用于宣传** | 🟡 | 需明确禁止或限制 |
| 涉软件：源码交付、著作权登记、开源许可合规 | 🟡 | 委托开发软件的权属与源码，须单独约定 |
| 第三方知识产权侵权责任 | 🟡 | 应由提供方担保 |

---

## 六、保密与数据

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 保密信息范围是否明确 | 🟡 | "一切信息"过宽，应定义范围与例外（公开、自有、第三方合法获得）|
| **保密期限**（合同期内 + 终止后X年）| 🟡 | 2-5年为常见；涉商业秘密可更长 |
| 保密义务主体（含员工、分包、关联方）| 🟡 | 建议约定乙方对其人员负保密责任 |
| **数据安全、个人信息保护**（涉数据处理时）| 🟡 | 涉个人信息需符合《个人信息保护法》，必要时签数据处理协议 |
| 保密违约金或赔偿 | 🟡 | 缺失则保密义务弱约束 |
| 合同终止后资料**返还/销毁** | 🟡 | 建议明确 |

---

## 七、违约责任与合同解除

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 乙方成果不达标/延期交付的责任 | 🟡 | 违约金与减价、解除的关系 |
| 甲方逾期付款、逾期配合的责任 | 🟡 | 对等性检查 |
| **任意解除权**：委托合同的法定任意解除 | 🟡 | 《民法典》第933条：委托合同当事人可随时解除，赔偿直接损失。技术服务/咨询若定性为委托，双方均有任意解除权——需评估并考虑特别约定 |
| 能否约定排除**任意解除权** | 🟡 | 可约定，但效力有争议，宜配合损害补偿条款 |
| 解除后的**费用结算**（已完成部分）| 🟡 | 建议约定按已完成工作量/里程碑结算 |
| 违约金上限与调减风险 | 🟢/🟡 | 《民法典》第585条 |
