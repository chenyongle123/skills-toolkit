# 招标代理 / 劳务合同专用检查清单

> 适用：招标代理委托合同、劳务分包合同、劳务派遣合同、专业作业分包合同、劳务用工协议。
> 主要法律依据：
> - 《民法典》委托合同章（第919-936条）、建设工程合同章（第788-808条）、总则编代理（第161-172条）
> - **《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》**（法释〔2020〕25号，下称"**施工解释一**"，尤其第5条劳务分包资质、第43条实际施工人）
> - 《招标投标法》及《招标投标法实施条例》《建筑法》
> - 《劳动合同法》（劳务派遣章）、《劳务派遣暂行规定》《保障农民工工资支付条例》
> - 《建设工程施工发包与承包违法行为认定查处管理办法》（住建部，转包/违法分包/挂靠认定标准）
> 立场差异提示：**招标代理**：招标人 vs 代理机构；**劳务**：发包人（总包/专业承包）vs 劳务承包人（劳务公司/班组）。

---

# 第一部分：招标代理委托合同

## 一、代理范围与权限

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **代理事项范围**是否明确（编制文件/发布公告/组织开标评标/协助定标/合同签订）| 🟡 | 范围不清易扯皮、追责无据 |
| 代理**权限**：是否有权代表招标人签署文件 | 🟡 | 越权代理的风险（《民法典》第171条）|
| 是否明确**不得转委托**或转委托条件 | 🟡 | 《民法典》第923条：未经同意转委托，代理人担责 |
| 招标人对代理工作的**监督、审核、确认**机制 | 🟢/🟡 | 建议关键文件须招标人书面确认 |

## 二、合法合规（招标代理的执业红线）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 代理机构是否具备相应**资质/资格** | 🔴 | 无资格代理可能导致招标无效、行政处罚 |
| 是否约定代理机构**泄露标底、串通投标**的责任 | 🔴 | 《招标投标法》：泄露标底、串通投标属违法，须明确禁止与责任 |
| 与投标人是否存在**利害关系**（需回避）| 🔴 | 代理机构不得与投标人有利益关系 |
| 招标文件、评标办法是否由招标人最终确认 | 🟡 | 防止代理机构越权设定倾向性条款 |
| 是否违反**法定招标程序与时限** | 🔴 | 程序违法可能导致中标无效 |
| 招标代理服务费：**向谁收取、标准、支付节点** | 🟡 | 需明确由招标人还是中标人付；避免"两头收费"违规 |

## 三、费用、责任与保密

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 代理费计算方式（固定/中标价比例）与支付条件 | 🟡 | "招标失败是否付费"需明确 |
| 代理机构**过错导致招标失败/无效**的赔偿责任 | 🟡 | 明确赔偿范围与上限 |
| 保密义务（标底、投标文件、商业秘密）| 🟡 | 期限与违约金 |
| 招标失败、重新招标的费用处理 | 🟡 | 常见争议点 |
| 资料移交（招投标全过程档案）| 🟢/🟡 | 建议约定移交清单与时限 |

# 第二部分：劳务分包 / 劳务派遣合同

## 四、主体与资质（红线区）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 劳务承包人是否具备**劳务作业法定资质**（或施工劳务资质）| 🔴 | 施工解释一第5条：**具有劳务作业法定资质**的承包人与总包/分包签订的劳务分包合同，不因"无施工资质"无效；反之，无劳务资质则可能违法分包 |
| 是否名为"劳务分包"实为**转包/违法分包** | 🔴 | 判定看是否只收管理费、是否只提供劳务、材料设备由谁供 |
| 是否对**主体结构**进行了劳务分包且非自行完成 | 🔴 | 主体结构必须承包人自行完成（《民法典》第791条）|
| 劳务派遣单位是否有**劳务派遣经营许可** | 🔴 | 无许可的派遣合同无效，用工单位承担连带责任 |
| 派遣用工是否超**10%临时性/辅助性/替代性**岗位比例 | 🟡 | 《劳务派遣暂行规定》：派遣用工不得超过用工总量10% |

## 五、用工与工资支付（中国法特有红线）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 是否落实**农民工工资专用账户 + 实名制 + 工资保证金** | 🔴 | 《保障农民工工资支付条例》：总承包单位负总责 |
| 是否约定**总包代发工资** / 分包工资支付监督 | 🔴 | 分包拖欠时总包先行清偿，防层层拖欠 |
| 是否要求劳务方提供**用工实名制**及考勤资料 | 🟡 | 总包防范用工风险的基础 |
| 工资发放记录、考勤、工资表的提供与核验 | 🟡 | 建议约定总包有权核验并直接代发 |
| **社会保险**缴纳责任归属 | 🟡 | 派遣工由派遣单位缴，劳务用工需明确 |
| **工伤责任**与工伤保险 | 🔴 | 转包/违法分包时，总包承担用工主体责任（工伤、劳资纠纷）|
| 是否以班组长个人名义签"劳务协议"（实际为个人承包）| 🔴 | 个人承包组织的用工，总包承担用工主体责任风险极高 |

## 六、劳务报酬、结算与争议

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 劳务费计价方式（固定总价/工程量单价/工时）与结算周期 | 🟡 | 计价与结算不清是劳务纠纷主因 |
| 是否以**业主付款**为付劳务费条件（背靠背）| 🔴/🟡 | **背靠背批复（法释〔2024〕11号）**：大型企业与中小企业间的背靠背约定**无效**；且涉**农民工工资**的不得以此拖欠（总包先行清偿）；无效后利息无约定按一年期LPR计 |
| 劳务费支付节点与**发放到人**的验证 | 🟡 | 建议预留工资发放凭证作为付款前提 |
| 劳务用工争议、上访、群体性事件的**责任与处置** | 🟡 | 明确各方处置义务与费用承担 |
| **违约金、保证金**（为防止讨薪/质量问题的约束）| 🟡 | 需评估合法性与可执行性 |
| 安全事故责任划分 | 🔴 | 转包/违法分包时责任连带 |
