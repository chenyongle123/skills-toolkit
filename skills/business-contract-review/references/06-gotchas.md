# 审核常见陷阱（好 / 坏 对照）

> 本文件用于校准审核输出的**信噪比**与**专业度**。每条给出「✗ 坏做法」与「✓ 好做法」。

---

## 陷阱 1：把通行样板条款报成风险

**为什么要紧**：过度报警会训练用户忽略报告。如果什么都是风险，就什么都不是风险。

### ✗ 坏
```
合同含标准的、对等的、符合行业惯例的质保条款。
助手：「🟡 质保条款要求质量保证，建议谈判。」
```

### ✓ 好
```
[跳过，不报]
```
公平合理、行业通行的条款直接略过。只报真正偏离或缺失的。

---

## 陷阱 2：只报"写了的不利条款"，漏报"该写没写的"

**为什么要紧**：中国法下，缺失关键条款比不利条款更危险——因为会适用法律默认规则，而默认规则常常对被保护方不利。

### ✗ 坏
```
合同没有任何违约责任条款。
助手：[不提，只分析已有的条款]
```

### ✓ 好
```
🔴 缺失：合同未约定任何违约责任。
后果：一方违约时，守约方只能依据《民法典》第577条主张实际损失，
且须自行举证损失金额，举证难度大、救济弱。
建议增加：「任何一方违反本合同约定，应向守约方支付违约金，
违约金为[合同总价的X%或每日XX元]，给守约方造成损失超过违约金的，
应就超出部分予以赔偿。」
```
**缺失的标准条款必须明确标为"缺失："并给出默认法律后果。**

## 陷阱 3：立场判断错误，导致红黄绿全部颠倒

**为什么要紧**：同一句话对不同立场意义相反。拿不准立场就下结论，是报告"翻车"的第一原因。

### ✗ 坏
```
合同："承包人不得因任何原因申请工期顺延。"
助手（默认站在发包人立场）：「🟢 该条款有效保护了发包人的工期利益。」
```
实际上用户是承包人——这句话是他的重大风险。

### ✓ 好
```
（先确认立场）「合同未明显显示贵方是哪一方。请确认：贵方是发包人，还是承包人？」
确认我方为承包人口后：
「🔴 条款"不得因任何原因顺延"将排除贵方对发包人原因（如提供图纸迟延、
图纸错误、未按约付款）导致的工期延误的权利，与《民法典》第803、804条
赋予承包人的顺延与索赔权冲突，建议修改为：因发包人原因……工期相应顺延。」
```
**立场不明，先问一句再往下走。**

## 陷阱 4：报告"看起来不利但其实无效"的条款，不核实合法性

**为什么要紧**：有些条款本身就是无效的，指出"这对我方不利、建议谈判"是错的——正确的提示是"该条可能无效，无需过于担心，但也别指望靠它"。

### ✗ 坏
```
合同："承包人放弃建设工程价款优先受偿权。"
助手（站在承包人立场）：「🟡 该条对我方不利，建议谈判删除。」
```

### ✓ 好
```
🔴/提示：该放弃优先受偿权的约定，若损害建筑工人利益，
依《施工解释一》第42条，发包人以此主张承包人不享有优先受偿权的，
人民法院不予支持。但需注意：能否对抗仍取决于是否损害工人利益，
建议不要依赖该条，尤其在涉及农民工工资时。
```
**对合同效力存疑的条款，给"效力分析"，而不是简单的"建议谈掉"。** 拿不准的注明"待法律核实"，不要冒充定论。

## 陷阱 5：把行业惯例当绝对标准

**为什么要紧**：不同行业、不同地域、不同规模，"正常"的标准不同。

### ✗ 坏
```
助手：「付款期限超过30天不常见，建议改为30天。」
```

### ✓ 好
```
助手：「付款期限为180天。较长的付款期会增加贵方（供货/服务方）的现金流压力。
建议力争缩短；若对方为大型企业/项目单位，可依据《保障中小企业款项支付条例》
主张不超过60日的法定付款期限。若贵方为大型企业采购方，则长期限属常见安排。」
```
**先看立场、看主体性质、看行业，再下"是否异常"的结论。**

---

## 陷阱 6：只读前几页，漏掉附件与专用条款里的"埋雷"

**为什么要紧**：施工、EPC、采购合同最危险的条款常在**专用条款、技术协议、工程量清单、补充协议、附件**里。

### ✗ 坏
```
36页合同只读了通用条款前10页，就出具"未发现重大问题"的结论。
```

### ✓ 好
```
分块读取全文（含全部专用条款与附件），并在报告中说明：
「已通读通用条款、专用条款及附件A技术协议、附件B工程量清单、附件C补充协议。」
若某附件无法读取，明确说明：「附件D为扫描件，未能读取，建议人工核查。」
```

## 陷阱 7：给出无法落地的"全部推翻重来"建议

**为什么要紧**：对方是国企/央企/垄断方时，其格式合同大部分条款首轮基本不可谈。不切实际地要求"全改"会浪费用户的谈判资本。

### ✗ 坏
```
对方为大型国企的施工合同。
助手：「🔴 建议将全部付款条款改为验收后30天付款，将质保金比例降为0。」
```

### ✓ 好
```
助手：「🟡 付款条件为验收后付至80%，质保金20%保留2年。
该类条款在大型国企格式合同中通常为固定安排、首轮基本不可谈，
建议以争取『质保金不超过3%』或『缩短保留期为1年』为折中目标。
另可争取『逾期付至80%的时点明确化』这类对方容易接受的微调。」
```
**匹配双方博弈态势，区分"必须改的"与"现实可谈的"。**

## 陷阱 8：不报"对自己有利"的条款

**为什么要紧**：用户需要知道哪些条款是好条款、谈判中不能丢。只报坏的不报好的，信息不完整。

### ✗ 坏
```
[只列风险项，不说哪条是我方的保护性条款]
```
### ✓ 好
```
在「提示性条款」或单列「对我方有利的条款」中说明：
「本合同第8.2条约定的逾期付款违约金（日0.5‰）对我方有利，谈判中应坚守。」
```

## 陷阱 9：把"免责/限责条款"一律报为风险

**为什么要紧**：合理的责任限制（如双方对等的赔偿上限）是商业常态，不是风险。要看是否对等、是否排除根本违约。

### ✓ 好
```
「🔴 该责任限制条款单方适用于贵方，而对方责任无上限，且未排除对方根本违约
与人身损害的责任——依《民法典》第506条，造成人身损害的免责条款无效，
但该条对对方仍有利。建议改为双方对等，并排除故意/重大过失与人身损害。」
```
**重点看"对等性"和"是否触碰法定无效红线"，而非"有没有限责"。**

---

## 陷阱 10：术语与依据不专业

**为什么要紧**：用户是专业人士，会挑剔。引用法条要准确、术语要规范。

### ✗ 坏
```
「依据《合同法》第X条」  ← 《合同法》已于2021.1.1被《民法典》取代
「根据法律规定，违约金不得超过合同金额的20%」 ← 中国法并无此统一上限
```

### ✓ 好
```
「依据《民法典》第585条：约定违约金过分高于造成的损失的，法院可予适当减少。」
「依据《民法典合同编通则解释》（法释〔2023〕13号）第65条：
约定的违约金超过造成损失30%的，人民法院一般可以认定为'过分高于造成的损失'。
注意：是'损失'的30%，不是合同总额的30%，且30%只是参考标尺、非法定上限；
恶意违约方请求减少违约金的，一般不予支持。」
```
**不编造法条，不臆造比例。引用前核对现行有效版本。**
> ⚠️ 特别注意：原《合同法解释（二）》第29条**已随该解释于2021.1.1废止**，
> 其"超过损失30%"的裁判思路已由**合同编通则解释第65条**明文承接。
> 引用时**必须引现行有效文件**，不得再引《合同法》或《合同法解释一/二》。
