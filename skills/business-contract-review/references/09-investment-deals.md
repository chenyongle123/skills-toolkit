# 投资侧合同专项检查清单（股权 / 合作开发 / 对赌回购 / EMC）

> **适用**：股权转让与增资、合作开发协议、对赌与回购安排、合同能源管理（EMC）、合资协议。
> **服务角色**：本方作为**投资人 / 业主 / 合作方**（不是施工方）。工程类条款另见 `01`，新能源项目条款另见 `08`。
> **版本**：v1.1.0（2026-10-22 新增）

---

## 〇、使用说明（先读）

1. 本清单的**对赌、回购、股权**部分大量依赖**司法裁判规则而非法律明文**，引用时须区分：
   **法律明文**（公司法、民法典）/ **会议纪要口径**（九民纪要，非法律、非司法解释）/ **商业建议**（我方谈判立场）。
   **不得把九民纪要写成"法律规定"**，不得把商业建议写成"法律要求"（SKILL.md 第七步"法定 vs 建议"标注）。
2. 《公司法》2023 年修订、2024 年 7 月 1 日施行，**新旧法衔接是本清单最大坑**，见第一节。
3. 国资、外资、上市公司涉及的**审批与进场交易**规则本清单只提示方向，**文号引用前须核对现行规定**。

## 一、股权转让与增资

### 1.1 出资义务（🔴 高频翻车区）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 标的是否为**未届出资期限的已认缴股权** | 🔴 | 《公司法》（2023修订）**第88条第1款**：由**受让人**承担缴纳出资义务；受让人未按期足额缴纳的，**转让人承担补充责任** |
| ⚠️ **时间界线（必查）** | 🔴 | **法释〔2024〕15号**：第88条第1款**仅适用于 2024-07-01 之后**发生的未届出资期限股权转让；此前的按原公司法等规定精神处理。**签约/转让行为发生日必须先确认，否则整条判断会错** |
| 转让股权是否存在**已届期未缴 / 非货币财产实际价额显著低于认缴额** | 🔴 | 《公司法》**第88条第2款**：转让人与受让人在出资不足范围内**连带责任**；受让人**不知道且不应当知道**的，由转让人承担 |
| 2024-07-01 前转让的责任判断 | 🟡 | 依原公司法等规定精神，实务结合转让时公司经营与偿债状况、转让对价是否公允、受让人出资能力等综合判断（**非机械适用第88条**）|
| 存量公司**认缴出资期限调整**义务是否履行 | 🟡 | 2024-06-30 前登记设立的有限责任公司，剩余认缴出资期限自 2027-07-01 起超过 5 年的，应在 2027-06-30 前调整至 5 年内——**依据为注册资本登记管理制度的相关规定，引用前须核对现行文本** |
| 出资是否**实缴到位**（验资/银行流水/财报/审计报告）| 🔴 | 仅凭工商登记的"实缴"字样不足为凭 |
| 非货币财产出资（土地使用权、技术、股权）的**评估与过户** | 🔴 | 高估出资触发第88条第2款连带；土地使用权出资须可过户且无权利负担 |

### 1.2 转让程序与效力

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 向股东以外的人转让是否**书面通知其他股东**、优先购买权是否处理 | 🔴 | 《公司法》第84条：书面通知，30 日未答复视为放弃；章程另有规定从其规定 |
| 股权变动时点是否明确 | 🟡 | 《公司法》第86条：受让人**自记载于股东名册时起**可向公司主张股东权利 |
| 公司章程对股权转让的**限制条款** | 🟡 | 章程可另作规定（**第84条**最后一句"公司章程对股权转让另有规定的，从其规定"）|
| 是否涉及**股权代持 / 隐名持股** | 🔴 | 代持还原涉及其他股东过半数同意等问题；新能源项目公司为规避资质或持股限制代持的，另有合规风险 |
| 标的股权是否**质押、冻结、查封**或存在权属争议 | 🔴 | |
| 是否涉及**国有股权** | 🔴 | 国有资本转让通常须评估、备案并**进场交易**（相关规定文号**须核对现行文本**）；未进场存在效力与合规风险 |
| 外资准入、经营者集中申报 | 🟡 | 触发门槛时未申报有行政处罚风险；规则须核对现行负面清单与申报标准 |
| **交割先决条件**与工商变更期限、未完成的处理 | 🟡 | |

## 二、对赌与回购

> **依据层级提示**：下述第 5 条出自《全国法院民商事审判工作会议纪要》（**法〔2019〕254号**）第 5 条，
> 属**司法裁判口径**，**不是法律、不是司法解释**。撰写报告时应写"九民纪要口径/裁判倾向"，**不得写"法律规定"**。

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 对赌**相对方是谁**：股东/实控人 vs 目标公司 | 🔴 | 与股东、实控人对赌：无其他无效事由的，认定有效并可实际履行（九民纪要第5条，实践中无争议）。**我方为投资人时，应力争以股东/实控人为回购义务人** |
| 与**目标公司**对赌的可履行性 | 🔴 | 九民纪要第5条：协议本身不因存在回购/补偿约定而无效，但**主张实际履行**须审查是否符合"股东不得抽逃出资"及股份回购的强制性规定 |
| 请求目标公司**回购股权** | 🔴 | 九民纪要第5条：目标公司**未完成减资程序的，人民法院驳回其诉讼请求**。**即：赢了官司也拿不到钱，除非先走完减资** |
| 请求目标公司**金钱补偿** | 🔴 | 九民纪要第5条：须有可供分配的利润；目标公司无利润或利润不足的，驳回或部分支持，今后有利润时可另行起诉 |
| 九民纪要引用的公司法条号已变动 | ⚠️ | 纪要原文引 2018 年《公司法》第35条（抽逃出资→**新法第53条**）、第142条（股份回购→**新法第162条**）、第166条（利润分配→**新法第210条**，违法分红见第211条**）。**2023 年修订后条号已变，引用前须按现行《公司法》核对**，不得照抄纪要中的旧条号 |
| 回购**触发条件**是否明确可量化 | 🟡 | "未能实现预设目标"未量化即无法触发 |
| 回购**程序安排**：通知、股东会决议、减资公告、债权人保护、期限 | 🔴 | 只约定实体权利不约定程序，等于约定了拿不到的权利 |
| 是否设**连带责任 / 保证担保**（股东、实控人及其配偶）| 🟡 | 投资人应争取连带，否则执行面窄 |
| 回购价款**计算方式、是否含利息、是否有上限** | 🟡 | |
| 回购权的**行使期限**（逾期是否失权）| 🟡 | 未约定期限则长期悬置，对义务人不公且对我方未必有利 |
| **共同出售权、反稀释、优先清算、领售权** | 🟡 | 商业条款（建议），非法定 |
| 业绩承诺的**计算口径**（扣非前后、合并/单体、审计机构）| 🔴 | 口径不同直接决定对赌是否触发 |

## 三、合作开发协议（新能源项目高发）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **开发权 / 项目资源**归属与排他性约定 | 🔴 | 未排他则对方可另寻合作方 |
| 项目**核准/备案、指标获取、并网指标**的办理责任方与时限 | 🔴 | 政策类依据**须查现行规定**（新能源项目指标与并网政策变动频繁）|
| **前期费用**承担与退出时的补偿/买断机制 | 🔴 | 前期投入沉没是此类协议第一纠纷源 |
| 项目公司**股权结构、出资节奏与里程碑挂钩** | 🟡 | 一次性出资而无里程碑约束，风险集中 |
| 一方退出/违约时的**股权处置与价格机制**（评估方法、折价）| 🔴 | 未约定价格机制必然诉讼 |
| 收益分配与**分红政策**、再投入决策机制 | 🟡 | |
| 公司治理：董事会席位、一票否决、公章与账户共管 | 🟡 | |
| 合作方**资质与信用**（是否具备开发能力、有无被执行）| 🟡 | 建议核查工商与执行信息，**不得凭合同自述认定** |
| 土地/屋顶资源由谁落实，落实不成的后果 | 🔴 | 与 `08` 第五节叠加审查 |

## 四、合同能源管理（EMC）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **节能量基准线**如何确定（历史能耗、实测、修正因子）| 🔴 | 基准线是全部争议的核心 |
| **测量与验证（M&V）方法**、测点、仪表校准、数据采集与确认流程 | 🔴 | 只写"按实际节能量结算"而无可操作的 M&V 方法，等于无约定 |
| 生产负荷、产品结构、气候等**调整因素**的处理 | 🔴 | 用能方减产导致节能量下降，责任如何分配 |
| 节能量**不达标**的责任（补足、减免、解除）| 🟡 | |
| **设备所有权**归属与合同期满的移交（无偿/残值）| 🔴 | 未约定则期满设备归属争议 |
| 用能方**停产、转产、搬迁、破产**的处理 | 🔴 | EMC 回收期长，此风险敞口最大 |
| 节能收益**分享比例、结算周期、逾期责任** | 🟡 | |
| 设备毁损、灭失风险与保险 | 🟡 | |
| **政策依据**：节能服务公司备案、财政奖励等要求 | ⚠️ | 相关规定与标准**修订频繁，引用前须核对现行文本**，本清单不给文号 |

## 六、本清单的已知边界（诚实声明）

- **新旧公司法衔接**（2024-07-01 分界）是本清单最高风险区。凡涉及未实缴股权转让，**必须先确认转让行为发生时点**再适用第 88 条。
- 九民纪要为**裁判口径**，随司法政策变化，**不得作为法律明文引用**。
- 国资交易、外资准入、经营者集中的**规则与文号本清单未附**，出具报告前须核对现行规定。
- 本清单不覆盖：基金募集与合伙协议、上市公司重大资产重组、境外投资架构（SPV/VIE）。
