# 工程施工 / EPC 分包合同专用检查清单

> 适用：建设工程施工合同、EPC 总承包合同、专业分包合同、劳务分包合同、专业作业分包合同。
> 主要法律依据：
> - 《民法典》第十八章建设工程合同（第788-808条）、承揽合同章（第770-787条，第808条指引适用）
> - 《建筑法》《招标投标法》及《招标投标法实施条例》
> - **《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》**（法释〔2020〕25号，2021年1月1日起施行，下称"**施工解释一**"）
> - **《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》**（法释〔2023〕13号，2023年12月5日起施行，下称"**合同编通则解释**"）
> - 《保障农民工工资支付条例》《建设工程质量管理条例》《建设工程安全生产管理条例》《保障中小企业款项支付条例》《建设工程价款结算暂行办法》《建设工程质量保证金管理办法》（建质〔2017〕138号）
> - **《最高人民法院关于大型企业与中小企业约定以第三方支付款项为付款前提条款效力问题的批复》**（法释〔2024〕11号，2024年8月27日施行，下称"**背靠背批复**"）
> - 《中华人民共和国安全生产法》（2021年修正，第49条安全生产管理协议）
> 立场差异提示：本合同类型**上下家的权利义务高度对立**（发包人 vs 承包人），必须明确我方立场后再判断。
> 条文核验说明：施工解释一共45条，本清单所引条文号均经与现行文本逐条比对（详见 `00-legal-basis-index.md`）。

## 一、主体与资质（命中问题即 🔴）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 承包人是否具备相应**建筑业企业资质**且未超越等级 | 🔴 | 施工解释一第1条：无资质/超越资质，合同**无效**；《建筑法》第26条 |
| 是否存在**借用资质（挂靠）**——投标、签约、实际施工主体不一致 | 🔴 | 施工解释一第1条(二)：无效；出借方与借用方对质量不合格损失承担连带责任（第7条） |
| 是否存在**转包**（承包人不实际施工、只收取管理费） | 🔴 | 《民法典》第791条、《建筑法》第28条、《民法典》第806条：发包人可解除合同 |
| 是否**违法分包**：分包给无资质单位 / 再分包 / 主体结构非自行完成 | 🔴 | 《民法典》第791条第3款；主体结构必须承包人自行完成 |
| 分包是否取得**发包人同意** | 🟡 | 《民法典》第791条第2款：经发包人同意方可分包，否则违约/无效风险 |
| 是否属于**必须招标**的工程而未经招标 | 🔴 | 施工解释一第1条(三)：必须招标未招标或中标无效，合同无效 |
| 勘察、设计、施工、监理是否由**同一主体或关联方**承担（禁止）| 🔴 | 施工/监理不得同一家；关联交易需披露 |
| **安全生产许可证**是否有效 | 🟡 | 无证施工属违法，且影响事故责任划分 |

## 二、招标投标与黑白合同（命中即 🔴）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 中标合同之外是否另签**背离实质性内容**的合同（黑合同）| 🔴 | 施工解释一第2条：以中标合同（白合同）为准；工期、价款、范围、质量均属实质性内容 |
| 是否存在**变相压价**：高于市价购房、无偿配套、让利、捐赠财物 | 🔴 | 施工解释一第2条第2款：可确认无效 |
| 合同实质性内容是否与**招标文件、投标文件、中标通知书**一致 | 🔴 | 施工解释一第22条：不一致时以招投标文件为结算依据 |
| 是否属**非必须招标自愿招标**＋另行订约背离 | 🟡 | 施工解释一第23条：以中标合同为结算依据（除客观情势变更外）|
| 有无**串标、围标、中标无效**迹象 | 🔴 | 中标无效则合同无效 |
| 履约保证金、投标保证金是否符合法定上限 | 🟡 | 《招标投标法实施条例》：投标保证金≤招标项目估算价2%；履约保证金≤中标合同金额10% |
| 合同是否存在**背靠背付款**（以收到业主/上游款项为付款前提，或按上游拨付比例同步付款）| 🔴/🟡 | **背靠背批复（法释〔2024〕11号）**：**大型企业**与**中小企业**间的此类约定**无效**（违反《保障中小企业款项支付条例》第6、8条，依《民法典》第153条第1款认定）；无效后利息无约定按一年期LPR计。**先核对我方与对方的企业规模划型**再定红黄 |

## 三、合同价与结算

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 计价方式：**固定总价 / 固定单价 / 可调价** 是否明确 | 🟡 | 约定不明易生争议。固定价一般不予鉴定（施工解释一第28条），需评估风险 |
| 工程量清单、图纸、技术标准是否作为合同附件 | 🟡 | 缺附件则范围不清；缺"发包人要求"（EPC）则设计责任不明 |
| **设计变更、洽商、签证**流程与计价规则是否约定 | 🟡 | 施工解释一第19条：设计变更致工程量/质量标准变化，不能协商一致的参照当地计价依据 |
| 是否约定**发包人逾期不答复视为认可竣工结算** | 🟡 | 施工解释一第21条：有此约定则发包人逾期视为认可——**站在承包人立场应力争加入；发包人立场应约定明确答复期** |
| 新增、漏项工程量的计价方式 | 🟡 | 常有争议，建议约定"参照合同单价/当地信息价" |
| 暂估价、暂列金额的使用与调整规则 | 🟢/🟡 | 门槛以下不报；金额重大且规则缺失报 🟡 |

## 四、工程款支付与资金（上下家核心对立点）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **预付款**比例、支付时间、抵扣方式 | 🟡 | 通常10%-30%；预付款保函是否要求需明确 |
| **进度款**支付节点、比例、审批周期 | 🟡 | 节点模糊（如"按形象进度"）易扯皮；建议量化 |
| 是否存在**垫资**及垫资利息约定 | 🔴/🟡 | 施工解释一第25条：约定垫资的利息高于同类贷款利率/LPR部分不予支持；无约定按工程欠款处理，无约定利息不支持 |
| **质保金（质量保证金）**比例 | 🟡 | 《建设工程质量保证金管理办法》：一般≤工程价款结算总额3%（原5%已下调）；返还期限见施工解释一第17条 |
| 是否明确**逾期付款利息**标准 | 🟡 | 施工解释一第26条：无约定按同期同类贷款利率或LPR计息 |
| 付款是否以**竣工结算完成**为前提且结算无期限 | 🟡 | 易形成"永远结不了算、永远付不了款"，承包人立场应力争结算期限 |
| 是否属《保障中小企业款项支付条例》约束的**机关/事业单位/大型企业**付款 | 🟡 | 该条例规定付款期限一般不超过60日，不得强制要求以审计结果作为结算依据（除法定情形）|
| 是否约定**以政府审计为结算前提** | 🟡 | 除法律或行政法规另有规定，不得强制；对承包人不利 |
| **履约保函/预付款保函细则**是否完备 | 🟡 | 开立行资格（如"全国性商业银行地市级及以上分支机构"）、见索即付还是一般保证、是否不可撤销、**有效期是否覆盖至缺陷责任期满**、保函费用承担——细节缺失会使后期索赔与置换被动 |

## 五、工期、质量与验收

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **开工日期**认定规则是否明确 | 🟢/🟡 | 施工解释一第8条有默认规则；建议明确以免争议 |
| **竣工日期**、验收程序、整改期限 | 🟡 | 施工解释一第9条：拖延验收、擅自使用有法定后果 |
| **工期顺延**的申请程序与确认机制 | 🟡 | 施工解释一第10条：约定"未按期申请视为不顺延"的按约定，但发包人事后同意或承包人有合理抗辩除外 |
| **工期违约金**（逾期竣工）日费率与**上限** | 🟡 | 常见日1‰-3‰，上限一般≤合同价5%-10%。过高可请求司法调减（《民法典》第585条；**合同编通则解释第65条**：超过损失30%一般认定为"过分高于"，但恶意违约方请求减少一般不予支持）|
| 质量标准、验收规范、不合格的处理 | 🟢/🟡 | 施工解释一第12条：承包人不修复，发包人可减少价款 |
| **未经竣工验收擅自使用**的后果 | 🟡 | 施工解释一第14条：擅自使用后不得以使用部分质量问题主张权利（地基基础和主体结构除外）——**发包人立场需特别注意** |
| 缺陷责任期/保修期的起算与期限 | 🟡 | 保修期不得低于法定最低期限（《建设工程质量管理条例》第40条）。**缺陷责任期一般为1年、最长不超过2年**（《建设工程质量保证金管理办法》建质〔2017〕138号第2条；约定超2年的按2年认定）；起算点自**通过竣工验收之日**起计，因发包人原因无法按期验收的，承包人提交验收报告90日后自动进入（同办法第8条）。**文件多处表述不一致时逐项标注待澄清，不得替文件裁决** |
| 是否要求**安全生产管理协议**（交叉作业/多个承包单位）| 🟡 | 《安全生产法》第49条：同一作业区域内有两个以上承包单位、可能危及对方安全的，应当签订安全生产管理协议，明确各自的安全生产职责；未约定则责任界面不清 |
| 是否明确**隐蔽工程验收**程序 | 🟡 | 缺失易在质量争议中不利 |

## 六、农民工工资与用工（中国法特有红线）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 是否落实**农民工工资专用账户、实名制、工资保证金** | 🔴 | 《保障农民工工资支付条例》：施工总承包单位负总责 |
| 是否约定**施工总承包单位代发工资** | 🔴 | 分包单位拖欠时总包先行清偿，防层层拖欠 |
| 是否要求分包单位提供**用工实名制资料** | 🟡 | 缺则总包无法防范用工风险 |
| 工伤、安全事故责任划分 | 🟡 | 转包/违法分包时总包承担用工主体责任 |
| 是否以"农民工工资"为名**变相讨薪**风险条款 | 🟡 | 注意区分班组长/包工头讨要工程款与真实工资 |

## 七、优先受偿权与其他

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 是否约定**放弃/限制建设工程价款优先受偿权** | 🔴 | **施工解释一第42条**：损害建筑工人利益的放弃约定不予支持。权利基础见《民法典》第807条 |
| 优先受偿权行使期限 | 🟡 | **施工解释一第41条**：最长18个月，自发包人应付工程价款之日起算——**承包人立场务必关注是否已过期** |
| 优先受偿权主体与范围 | 🟡 | **施工解释一第35-40条**：主体为与发包人订立施工合同的承包人（第35条）；优先于抵押权和其他债权（第36条）；范围不含逾期利息、违约金、损害赔偿金（第40条）|
| **保修担保、履约担保、预付款担保**是否对等 | 🟡 | 单方要求我方提供多重担保而不对等，需评估 |
| 是否约定**甲供材**范围、数量、扣回方式 | 🟡 | 甲供材超欠供扣款规则缺失易争议 |
| 保险责任（建筑工程一切险、第三者责任险）归属 | 🟢/🟡 | 建议明确投保义务人 |
| 总分包之间的**连带责任**与追偿 | 🟡 | 分包人对其工作成果与总包向发包人承担连带责任（《民法典》第791条） |
| 转包/违法分包情形下**实际施工人**直接诉发包人 | 🔴 | 施工解释一第43条：实际施工人可诉转包人/违法分包人；可追加发包人在欠付范围内担责 |

## 八、EPC 特有检查点

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **设计责任**归属：设计缺陷由谁承担 | 🟡 | EPC 通常由总承包人承担设计责任，需与合同一致 |
| **发包人要求（Employer's Requirements）**是否完备 | 🟡 | 是判断性能达标的基础，缺失则验收无据 |
| **性能指标**（发电量/效率/产能）与罚则 | 🟡 | 新能源/工业 EPC 常见"性能考核违约金"，需评估可达性 |
| 设计、采购、施工**接口责任**划分 | 🟡 | 接口不清易互相推诿 |
| **不可抗力、法律变化、物价波动**的价格调整机制 | 🟡 | 长期 EPC 合同风险大，调价机制缺失是重大风险 |
| 试运行、性能考核、缺陷责任期与最终验收 | 🟡 | 与质保金返还挂钩，需明确 |

## 九、缺失条款清单（该有而没写 → 逐项报）

- [ ] 五方主体全称、统一社会信用代码、法定代表人（主体不明）
- [ ] 工程范围、承包方式、计价方式的明确界定
- [ ] **合同文件组成与解释顺序**（多文件冲突时按何者适用）
- [ ] **履约保函/预付款保函的开立行资格、见索即付属性与有效期**
- [ ] 设计变更与签证的书面流程
- [ ] 竣工验收的组织、标准、期限
- [ ] 质量保证金比例与返还期限
- [ ] 逾期付款/逾期竣工的违约责任
- [ ] 农民工工资支付保障条款（施工类必须）
- [ ] 争议解决方式（诉讼/仲裁二选一，管辖法院或仲裁机构明确）
- [ ] 不可抗力与情势变更处理
- [ ] 合同解除条件与已完工程的结算
- [ ] **安全生产管理协议**（交叉作业时，《安全生产法》第49条）
- [ ] 送达条款（地址、方式、视为送达）
- [ ] 附件清单（图纸、清单、技术协议、发包人要求）
