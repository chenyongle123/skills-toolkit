# 通用条款检查清单（四类合同均叠加适用）

> 无论何种合同类型，以下条款都应检查。**本清单与专用清单叠加使用。**
> 主要法律依据：
> - 《民法典》总则编（第143、146、151、153、154条）、合同编通则（第464-594条，尤其第496-497条格式条款、第577、584、585条违约责任、第590条不可抗力）
> - **《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》**（法释〔2023〕13号，2023年12月5日起施行，下称"**合同编通则解释**"）
> - 《民事诉讼法》（第35条协议管辖）及《民诉法解释》
> 说明：合同编通则解释系统整合了原《合同法解释一》《合同法解释二》的裁判规则，是审查合同效力、违约金、格式条款时的**首要司法解释依据**。

---

## 一、主体资格与签约主体（打地基）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 当事人**全称、统一社会信用代码、法定代表人/负责人**是否准确 | 🔴 | 主体错误、名称与营业执照不符 → 合同相对人无法确定 |
| 签约主体是否具备**民事行为能力与经营范围** | 🟡 | 超越经营范围不一定无效（《民法典》），但可能合规风险 |
| 签约代表是否有**签约授权**（授权委托书）| 🔴 | 无权代理 → 合同效力待定（《民法典》第171条）|
| 是否为**分公司**（无独立法人资格）签约 | 🟡 | 建议由总公司追认或提供授权 |
| 是否存在**关联交易**需披露 | 🟡 | 上市公司/国企有合规要求 |
| 主体是否被列入**失信名单、经营异常、严重违法** | 🟡 | 尽调提示，不属条款本身 |

---

## 二、合同效力（无效与可撤销）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 是否违反**法律、行政法规强制性规定** | 🔴 | 《民法典》第153条：违反强制性规定无效 |
| 是否违背**公序良俗** | 🔴 | 《民法典》第153条第2款 |
| 是否存在**虚假意思表示**（阴阳合同/抽屉协议）| 🔴 | 《民法典》第146条：虚假表示无效，隐藏行为按实际处理。**合同编通则解释第14条**：同一交易订立多份合同，以虚假意思表示订立的无效；被隐藏合同的效力依第153条第1款/第502条第2款判断 |
| 是否存在**恶意串通损害他人利益** | 🔴 | 《民法典》第154条：无效 |
| 是否存在**重大误解、欺诈、胁迫、显失公平** | 🟡 | 可撤销（《民法典》第147-151条），注意1年除斥期间 |
| 格式条款是否尽到**提示说明义务** | 🟡 | 《民法典》第496-497条：未提示可主张不成为合同内容；不合理免责条款无效。**合同编通则解释第10条**：采用足以引起注意的文字/符号/字体等明显标识即认定已履行提示义务，且举证责任在**提供方**；**第9条**：仅以"系合同示范文本制作"或"双方已约定不属格式条款"为由主张非格式条款的，**法院不予支持**——我方使用自制合同模板时须特别注意 |

---

## 三、对价与对等性

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 权利义务是否**显失公平/严重失衡** | 🟡 | 单方免责、单方解除、单方变更权需警惕 |
| 是否只约束一方而对方无对应义务 | 🟡 | 典型如单方审计权、单方解释权 |
| 违约责任是否**对等** | 🟡 | 我方违约高额罚、对方违约免责，需争取对等 |
| 单方**变更权、解释权、最终认定权** | 🔴/🟡 | "以甲方通知为准""甲方有权随时调整"是重大风险点 |

---

## 四、违约责任

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 违约金**计算方式**是否明确 | 🟡 | 日费率、基数、上限、起止时间 |
| 违约金是否**过高**（可被调减）| 🟡 | 《民法典》第585条。**合同编通则解释第65条**：以第584条损失为基础衡量，**超过损失30%一般可认定"过分高于"**（注意是"损失"的30%，非合同总额）；恶意违约方请求减少一般不予支持。**第64条**：违约方主张调整应承担举证责任；约定"不得调整违约金"无效 |
| 违约金是否过低（不足以覆盖损失）| 🟡 | 可约定损失赔偿与违约金并存/择一 |
| 是否排除**间接损失/可得利益损失** | 🟡 | 关键合同应力争涵盖；供货方/服务方立场常需排除 |
| 是否约定**损失赔偿的计算方法** | 🟡 | 缺失则举证困难 |
| 是否有**违约金上限** | 🟢/🟡 | 上限过低对守约方不利 |
| 违约责任与解除权的关系 | 🟡 | 达到何种违约可解除，应明确 |

## 五、争议解决

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 选择**诉讼**还是**仲裁**（二者只能择一）| 🟡 | 同时约定两者无效 |
| 诉讼：约定管辖法院是否合法 | 🟡 | 《民事诉讼法》第35条：只能约定被告住所地、合同履行地、合同签订地、标的物所在地、原告住所地等有实际联系地，不得违反级别/专属管辖 |
| 仲裁：**仲裁机构名称**是否唯一、准确 | 🔴 | 约定不明（如"当地仲裁机构"）可能致仲裁条款无效 |
| 是否约定**前置协商/调解**程序 | 🟢 | 一般性条款 |
| 适用**法律**（涉外时）| 🟡 | 涉外合同需明确准据法 |
| 争议期间的**继续履行义务** | 🟢/🟡 | 建议约定争议不影响无争议部分履行 |

---

## 六、不可抗力与情势变更

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 不可抗力的**定义与范围** | 🟡 | 《民法典》第180、590条：不能预见、不能避免、不能克服的客观情况 |
| 通知义务与**证明**提供 | 🟡 | 应在合理期限内通知并提供证明，否则不能免责 |
| 不可抗力持续过久的**解除权** | 🟡 | 建议约定 |
| 是否排除**情势变更** | 🟡 | 《民法典》第533条：情势变更可请求变更或解除，当事人不得以约定排除法定救济 |
| 疫情、政策、限电等是否列为不可抗力/可调价 | 🟢/🟡 | 行业惯例相关，建议明确 |

---

## 七、通知与送达

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 约定的**联系地址、联系人、电话、邮箱**是否完整 | 🟡 | 送达条款缺失 → 通知无法证明送达 |
| 通知方式（书面/挂号信/快递/邮件）与**生效时间** | 🟡 | 建议约定"寄出后X日视为送达" |
| 地址变更的**通知义务** | 🟡 | 未通知的按原地址送达有效 |
| 是否约定司法文书送达地址确认 | 🟡 | 诉讼中"送达难"的防范，强烈建议加入 |

---

## 八、合同生效、变更与解除

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 生效条件：**签字 / 盖章 / 签字并盖章** | 🟡 | 明确"签字并盖章"或"签字或盖章"，避免效力争议 |
| 是否需**审批/备案**后生效（如涉外、涉国有资产）| 🟡 | 附生效条件需明确 |
| 变更须**书面**并经双方签署 | 🟡 | 口头变更举证困难 |
| **解除条件**与解除后的结算、清理 | 🟡 | 建议明确解除后费用结算与资料返还 |
| 合同份数、附件效力 | 🟢 | 一般条款，建议明确"附件与正文具同等效力" |

---

## 九、通用缺失条款清单（每份合同都查）

- [ ] 当事人完整身份信息（名称、信用代码、法定代表人、地址、联系方式）
- [ ] 签约代表的授权证明
- [ ] **合同文件组成与解释顺序**（正文、附件、补充协议冲突时按何者适用；缺失本身即风险）
- [ ] 违约责任（计算方式、上限、损失赔偿）
- [ ] 争议解决（诉讼/仲裁择一 + 明确管辖/机构）
- [ ] 不可抗力（定义、通知、证明、解除）
- [ ] 通知送达（地址、方式、视为送达、地址变更）
- [ ] 生效条件、变更与解除
- [ ] 保密条款（如适用）
- [ ] 附件清单与效力
- [ ] 全过程文件（授权、往来函件）签署保存要求
