> 我方为**总承包人**（发包给分包人）。展示审核报告的完整形态与专业深度。

---

## 输入

> 「帮我审一下这份光伏电站支架安装分包合同，我们是总包，合同额 860 万，工期 90 天，
> 对方是分包老板给的模板，催着签。」

合同：38 页，含通用条款、专用条款、附件A工程量清单、附件B安全协议、附件C甲供材清单。

## 一、高风险提示（🔴 签约前必须解决）

### 🔴 1. 分包人资质未核实——合同效力风险（致命项）

**原文**：附件主体信息栏中，分包人「建筑业企业资质等级」栏为空白。

**问题**：分包人未载明施工资质。若分包人无相应资质或超越资质等级，依《施工解释一》第1条，
本合同应认定**无效**；即便工程合格，我方也只能参照合同折价补偿，且我方作为总包可能被追究违法分包责任。

**法律依据**：《民法典》第791条、《建筑法》第26条、《施工解释一》第1条、第7条。

**建议**：
```
签署前必须取得分包人有效的①营业执照 ②建筑业企业资质证书（核对资质类别与等级是否覆盖
本工程范围）③安全生产许可证，作为合同附件并注明"附件D：承包人资质文件"。
在合同第X条增加：「承包人保证其具备承接本工程所需的全部资质，并保证资质在合同履行期间持续有效。
因承包人资质问题导致合同无效或被行政处罚的，全部损失及罚款由承包人承担。」
```

**优先级**：必改（未核实前不建议签署）
**退让方案**：无——资质是强制性红线，不存在让步空间。

---

### 🔴 2. 存在"以劳务分包之名行转包之实"的风险敞口

**原文**：第3.2条「承包人可自行组织人员完成本合同工作，具体施工队伍由承包人安排。」

**问题**：合同未禁止分包人再分包或转包。支架安装若被分包人整体转手给个人班组，
我方可能被认定为违法分包的上游，承担连带责任。

**法律依据**：《民法典》第791条第2、3款；《施工解释一》第43条（实际施工人可诉发包人）。

**建议**：
```
增加：「承包人不得将本合同项下工程转包、违法分包或肢解后分包给第三人，
不得允许他人以承包人名义承揽本工程。违反的，发包人有权立即解除合同，
承包人按合同总价的20%支付违约金，并赔偿由此造成的全部损失。」
并增加：「承包人的现场施工人员名单及身份信息应向发包人备案，实行实名制管理。」
```

**优先级**：必改

---

### 🔴 3. 未约定农民工工资支付保障机制——法定强制义务缺失

**原文**：全合同未见农民工工资专用账户、实名制、总包代发等任何约定。

**问题**：依《保障农民工工资支付条例》，**施工总承包单位对所承包工程项目的农民工工资支付负总责**，
即使分包人拖欠，我方（总包）也须先行清偿。合同不作约定，等于我方承担了责任却没有对应的管理抓手和追偿依据。

**法律依据**：《保障农民工工资支付条例》第26、30、36条。

**建议**：
```
增加：「本合同项下全部农民工工资纳入农民工工资专用账户管理，由发包人通过专用账户
实行总包代发。承包人应按月提供经工人本人签字的工资表、实名制考勤记录。
发包人有权直接从应付工程款中划扣代发工资，承包人无异议。
因承包人拖欠农民工工资导致发包人被追索的，发包人有权全额向承包人追偿，
并有权从工程款、质保金中直接扣除。」
```

**优先级**：必改

---

### 🔴 4. 甲供材（附件C）金额超过合同价，但未约定超欠供处理

**原文**：附件C甲供材清单列示钢材等材料，但合同正文未约定甲供材的移交、超欠供扣款规则。

**问题**：甲供材若超供无法扣回、欠供无人担责，将造成我方直接经济损失。
金额较大时属重大敞口。

**法律依据**：《民法典》第776条（定作人提供材料）。

**建议**：
```
增加：「甲供材料由双方按清单办理交接签收。材料用量以[定额/图纸]理论用量加X%合理损耗为准，
超用量部分由承包人以甲供材料实际采购价向发包人偿付，欠用量据实核减工程款。
承包人负责甲供材料的现场保管，因保管不善造成损失、丢失、损坏的，由承包人赔偿。」
```

**优先级**：必改

## 二、需谈判的条款（🟡）

### 🟡 5. 工期违约金上限过低

**原文**：第9.3条「承包人逾期竣工的，每日支付违约金 2000 元，累计不超过合同总价的 1%。」

**问题**：1% 上限即 8.6 万元。对 90 天工期的关键项目，逾期对我方造成的窝工、并网延误损失可能远超此数。
违约金过低将不足以弥补实际损失。

**法律依据**：《民法典》第585条。

**建议修改**：
```
「承包人逾期竣工的，每日按合同总价的 1‰ 支付违约金，累计不超过合同总价的 10%；
违约金不足以弥补发包人实际损失的，承包人应就超出部分予以赔偿。」
```
**优先级**：应力争
**退让方案**：若对方坚持上限，可退至"累计不超过 5% + 明确约定逾期导致并网延误的额外损失另行赔偿"。

---

### 🟡 6. 质量保证金比例与返还节点不明

**原文**：第10.1条「工程款支付至 90%，余款作为质量保证金，待工程验收后返还。」

**问题**："验收后"未明确是竣工验收还是质保期满，返还节点模糊；且 10% 比例高于《建设工程质量保证金管理办法》
通常不超过 3% 的惯例。

**建议修改**：
```
「工程款支付至结算总价的 97%，余款 3% 作为质量保证金，
自工程竣工验收合格之日起满 [12] 个月且无质量问题后 14 日内无息返还。」
```
**优先级**：应力争
**退让方案**：比例为 5% 时可接受，但必须明确返还节点为"质保期满后 X 日内"。

---

### 🟡 7. 争议管辖约定对我方不利

**原文**：第15.2条「因本合同发生争议，由承包人所在地人民法院管辖。」

**问题**：约定在对方所在地诉讼，我方将承担异地诉讼成本与主场劣势。
依《民事诉讼法》第35条，合同履行地、被告/原告住所地等均可约定，我方有谈判空间。

**建议修改**：
```
「……由工程所在地或发包人住所地人民法院管辖。」
```
**优先级**：应力争
**退让方案**：约定"工程所在地人民法院管辖"（工程所在地本身有实际联系，且便于证据调取）。

---

### 🟡 8. 未约定结算答复期限

**原文**：全合同未约定竣工结算的审核期限与逾期视为认可的规则。

**问题**：作为**发包人**，我方在此处其实是有利的一方——若不加约定，对方结算迟迟不确定。
但注意：若对方后续主张，可能援引对我方不利的默认规则。建议主动约定**我方**的答复期限，
避免"逾期不答复视为认可对方结算"的不利结果。

**建议修改**：
```
「承包人提交竣工结算文件后，发包人应在 [60] 日内予以答复；
发包人在前述期限内未答复的，承包人可以催告，发包人应于收到催告后 14 日内答复。」
（注意：站在发包人立场，应避免约定"逾期不答复即视为认可承包人结算文件"。）
```
**优先级**：应力争
**退让方案**：可接受"约定期限内答复"，但不同意"逾期视为认可"。

## 三、提示性条款（🟢 仅供知晓）

- **付款节点**：预付款 20%（需提供预付款保函）、按月计量支付至 80%、结算后付至 97%（详见第10条）
- **质保期**：竣工验收合格之日起 12 个月
- **通知期限**：工期顺延须在事件发生后 **3 日内**书面提出，逾期视为放弃（第7.4条）——**我方须在项目管理中提示分包人遵守，否则可能被对方主张失权**
- **联系人及送达地址**：已载明，方式为书面 + 邮件
- **我方有利条款**：第8.5条约定承包人原因造成质量不合格的无偿返工义务，对我方有利，谈判中应坚守

## 四、合同要点摘要

光伏电站支架安装工程，我方（总包）将支架安装工作分包给 XX 安装公司，
固定单价、合同额 860 万、工期 90 日历天。分包人负责安装并自行组织人员，
我方按月度计量支付、预留质保金、提供甲供钢材。工程验收合格后进入 12 个月质保期。

| 农民工工资保障机制 | 我方依法承担总包代发/清偿责任却无追偿依据 | 🔴 必须补 |
| 甲供材超欠供扣款规则 | 超供无法扣回，直接经济损失 | 🔴 必须补 |

## 六、谈判策略

| 争点 | 我方诉求 | 主张话术 | 可接受的折中 |
|---|---|---|---|
| 资质与合法性 | 提交资质文件，写入保证条款 | "这是双方合规的基础，也是保护双方" | 无（红线）|
| 农民工工资 | 纳入总包代发 | "既是法定要求，也让工人安心、避免讨薪" | 至少约定实名制 + 工资表备案 |
| 转包禁止 | 明确禁止 + 高额违约金 | "合同对象是你们公司，不能变相转手" | 违约金比例可谈 |
| 工期违约金 | 提至日1‰、上限10% | "关键节点，延误损失是实打实的" | 5% 上限 + 特别约定并网延误损失 |
| 质保金 | 降至3%、明确返还节点 | "3%是行业惯例" | 5% + 明确节点 |
| 管辖 | 工程所在地或我方所在地 | "工程所在地取证方便" | 工程所在地 |

**谈判优先级**：4 个 🔴 项是签约前提，不解决不签。🟡 项中，工期违约金与质保金是主要谈判筹码，
可用"管辖让步"换取"违约金提升"。

**对方模板提示**：本合同为分包人提供的模板，属对方格式文本，预期我方会提出修改，
谈判空间较大；但对方为中小分包商，对农民工工资、资质等合规条款反应通常正面，可优先沟通。

## 七、下一步

1. **【签约前】** 取得并核验分包人营业执照、建筑业企业资质证书、安全生产许可证（🔴 前置条件）。
2. **【签约前】** 补齐 4 项 🔴 条款与附件。
3. **【签约前】** 就 3 项 🟡 项与对方沟通，按优先级出价。
4. **【履约中】** 建立工期顺延 3 日申报提醒机制、农民工工资台账与甲供材签收台账。
5. **【存档】** 全过程书面文件（变更、签证、验收、往来函件）归档。
