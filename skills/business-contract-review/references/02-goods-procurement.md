# 物资设备采购合同专用检查清单

> 适用：设备采购合同、材料采购合同、物资供应合同、供货框架协议、采购订单。
> 主要法律依据：
> - 《民法典》合同编买卖合同章（第595-647条）、承揽合同章（第770-787条，定制设备时）
> - **《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》**（法释〔2020〕17号，2020修正，下称"**买卖合同解释**"）
> - **《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》**（法释〔2023〕13号，下称"**合同编通则解释**"）
> - 《产品质量法》《招标投标法》（如涉招标采购）《保障中小企业款项支付条例》
> 立场差异提示：采购方 vs 供货方。**质量保证、付款节奏、退换货、违约赔偿**是核心对立点。

---

## 一、主体与标的

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 供货方是否具备**生产经营资质/许可**（特种设备、危化品、计量器具等）| 🟡/🔴 | 无证供货可能导致产品无法验收，甚至合同无效（强制性规定）|
| 是否属**代理商/经销商**而非生产商，授权链是否完整 | 🟡 | 需查验授权书，防止"厂货"无法质保 |
| **标的物**名称、规格型号、品牌、技术参数是否唯一可识别 | 🔴 | 标的不明 = 交付争议、以次充好无从追责 |
| 是否附带**技术协议/技术规格书**作为合同附件 | 🟡 | 是验收的技术依据，缺失则验收无标准 |
| 产地、制造商、是否原装进口 | 🟢/🟡 | 涉及关税、质保、配件供应的差异 |

---

## 二、质量标准与验收（采购方核心利益）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 质量标准依据：国标 / 行标 / 企标 / 双方约定 | 🟡 | 《民法典》第615条：应按约定/约定不明按国家标准、行业标准 |
| 是否约定**到货验收 + 安装调试 + 最终验收**三阶段 | 🟡 | 一阶段验收易放过隐蔽缺陷 |
| **验收期限**与逾期未提出异议视为合格的规则 | 🟡 | 《民法典》第621条：约定检验期间，逾期视为合格；**采购方立场务必留足检验期**。**买卖合同解释第12条**："二年"是最长合理期限且为不变期间；**第14条**：检验期/合理期限/二年期经过后，主张数量或质量不符的不予支持 |
| 验收标准是否**客观可量化**（避免"满足使用要求"等主观表述）| 🟡 | 主观标准 = 验收扯皮 |
| 是否约定**隐蔽瑕疵**的追责（超出检验期仍可追）| 🟡 | 隐蔽瑕疵不受检验期限制（《民法典》第621条第3款）|
| 抽样检验、第三方检测机构的指定与费用承担 | 🟢/🟡 | 建议约定权威检测机构及不合格时费用由供货方承担 |
| 是否要求提供**合格证、检验报告、质保书、说明书、装箱单** | 🟡 | 缺失随货资料影响验收与后续质保 |

---

## 三、交付、运输与风险转移

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **交货方式**：送货上门 / 自提 / 代办运输 | 🟡 | 决定运费、保险、装卸责任 |
| **风险转移时点**：交付时 / 验收合格时 | 🔴/🟡 | 《民法典》第604条：标的物毁损灭失风险交付前由出卖人承担。**采购方立场应力争"验收合格后转移"**。**买卖合同解释第9-11条**：送货至指定地点交承运人后风险转移；在途货物出卖人知情未告知、种类物未特定化时，风险仍由出卖人负担 |
| **所有权保留**条款（供货方立场）| 🟡 | 《民法典》第641条：可约定价款付清前所有权归出卖人，需登记对抗 |
| 运输保险、装卸、二次搬运责任 | 🟢/🟡 | 明确由谁投保、费用归属 |
| 交货地点、交货期、**逾期交货**违约金 | 🟡 | 逾期交货违约金日费率与上限；与工期/投产节点挂钩的设备需强调 |
| 包装标准、标记、随货单据 | 🟢 | 一般性条款 |
| **分批交货**与部分验收、部分付款 | 🟡 | 明确各批次独立验收与结算 |

---

## 四、价格、付款与发票

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 单价、总价是否**含税、含运费、含安装调试** | 🟡 | 不含税/含税不明确 = 结算争议、税负转嫁 |
| 税率、发票类型（专票/普票）、**开票时间** | 🟡 | 采购方立场务必明确"先票后款/先款后票"，影响抵扣 |
| 付款节点：**预付 / 到货 / 验收 / 质保金** 比例 | 🟡 | 采购方应力争"验收后付款"，减少预付比例 |
| 预付款比例是否过高 | 🟡 | 通常≤30%；高价设备需评估供货方履约能力 |
| **质量保证金**比例与返还时间 | 🟡 | 采购方立场保留质保金是重要保障；比例与返还节点需明确 |
| 是否约定"背靠背"付款（收到上家款再付，或按上游拨付比例同步付款）| 🔴/🟡 | **背靠背批复（法释〔2024〕11号，2024-08-27施行）**：**大型企业**与**中小企业**间的此类约定**无效**（违反《保障中小企业款项支付条例》第6、8条，依《民法典》第153条第1款认定）；无效后利息无约定按一年期LPR计。**先核对双方企业规模划型**：中小企业供货时可直接主张条款无效；我方为大型采购方时不得依赖此条拖付款 |
| 价格调整机制（原材料波动、汇率）| 🟢/🟡 | 长期合同/大宗物资需评估 |
| 是否约定**逾期付款违约金** | 🟡 | 缺失则按LPR计息。**买卖合同解释第18条**：无约定时，2019.8.20后按一年期LPR加计30-50%计算逾期付款损失 |

---

## 五、质量保证与售后

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **质保期**起算（交付/验收/投产）与期限 | 🟡 | 起算点争议大，采购方应力争"验收合格/投产之日起算" |
| 质保范围：**三包**、免费维修、更换、退货 | 🟡 | 明确响应时间、到场时间、修复时限 |
| **备品备件**供应承诺期限 | 🟡 | 关键设备应约定停产后的备件保障年限 |
| 软件/控制系统是否含**升级、授权、服务费** | 🟡 | 隐性成本，需明确是否另收费 |
| 技术服务、培训、安装指导是否含在价内 | 🟢/🟡 | 建议明确 |
| 质量异议与**退换货**条件 | 🟡 | 明确不合格品的退、换、修理选择权归属 |

---

## 六、违约责任与赔偿

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 供货方质量违约：修理/更换/退货/减价/赔偿 | 🟡 | 《民法典》第582条：可合理选择违约责任方式 |
| 是否约定**违约金上限**（常见"不超过合同总价X%"）| 🟡 | 上限过低可能不足以覆盖损失；过高可被调减（《民法典》第585条）|
| 是否约定**间接损失/停产损失**赔偿 | 🟡 | 供货方立场通常排除间接损失；采购方（尤其关键设备）应力争涵盖 |
| 是否排除**根本违约**责任 | 🔴 | 排除根本违约责任、排除人身损害责任的条款可能无效 |
| 采购方逾期提货/逾期付款的责任 | 🟡 | 对等性检查 |
| 不可抗力通知与免责 | 🟢/🟡 | 一般性条款，但需明确通知义务与期限 |

---

## 七、知识产权与合规

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 设备/软件涉及的**知识产权侵权**担保 | 🟡 | 供货方应保证不侵权，第三方索赔由供货方承担 |
| 定制开发的**成果归属**（如为非标设备/含软件）| 🟡 | 明确是买卖（所有权转移）还是承揽+开发（成果归属）|
| 是否含**开源软件**及合规风险 | 🟢/🟡 | 涉软件设备需评估 |
| 反商业贿赂、廉洁条款 | 🟢 | 国企/大型企业常有强制要求 |
