# 新能源项目（风电 / 光伏 / 储能）专项检查清单

> **适用**：风电、光伏（集中式与分布式）、储能电站的 EPC 总承包、设备采购、运维委托、EMC、屋顶/土地租赁、合作开发协议。
> **定位**：本清单是 `01-construction-subcontract.md` 的**叠加层**，不是替代品。审新能源 EPC 时**两份都要跑**。
> **版本**：v1.1.0（2026-10-22 新增）

---

## 〇、使用说明（先读三条纪律）

1. **本清单大量检查点属于"商业/技术条款"，不是法定要求。** 引用依据时必须区分：
   - **法定**（可引法律、行政法规、司法解释）；
   - **商业建议**（只能写"行业惯例/我方谈判建议"，**不得包装成"法律规定"**——违反 SKILL.md 第七步"法定 vs 建议"标注要求）。
2. **政策与标准类依据（可再生能源法、电力业务许可证、绿证规则、辅助服务管理、涉网试验国标等）修订频繁。**
   **本清单刻意不写具体条号与文号**——出具报告前**必须检索官方现行文本核对**，不得以本文表述代替。
   可查：国家法律法规数据库（flk.npc.gov.cn）、国家能源局官网（nea.gov.cn）、国家发改委官网（ndrc.gov.cn）。
3. **先定立场**：业主（投资侧）与 EPC 承包人对下述每一条的方向**基本相反**，未确认立场时按双栏输出。

## 一、性能保证与发电量考核（新能源 EPC 第一争点）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 是否约定**首年/逐年上网电量保证值**（或等效利用小时数）| 🟡 | 商业条款（建议）。缺失则业主无考核抓手 |
| **考核口径**是否明确：并网点计量 vs 关口表、是否含弃风弃光、是否含厂用电 | 🔴 | 口径不同可致数个百分点差异，是争议高发点 |
| **资源修正方法**是否约定（辐照/风速实测值与设计值偏差如何修正）| 🔴 | 缺失则承包人承担全部资源风险，或反之业主被"资源差"免责架空 |
| 是否明确**限电（弃风弃光）由谁承担**、是否计入保证值 | 🔴 | 电网限电非承包人过错，应排除；未约定则必争 |
| PR（性能比）值 / 系统效率保证值及其**测试方法与测试期** | 🟡 | 测试标准、测点、天气筛选条件须明确 |
| 性能考核**违约金的计算方式与上限** | 🔴 | 无上限的考核罚款对承包人是敞口风险；业主立场则应力争有牙齿 |
| 考核不达标的**补救顺序**：整改 → 重测 → 罚款 → 解除 | 🟡 | 缺失则一次不达标即触发重罚，对承包人不公 |
| **性能考核与质保金返还、最终验收的挂钩关系** | 🟡 | 未挂钩则考核罚则难落地 |

---

## 二、设备与材料质保（金额大、周期长）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 光伏组件**功率衰减质保**：首年衰减率、逐年衰减率、期末（25年）保持率 | 🔴 | 商业条款（建议）。仅写"按厂商标准"视为**约定不明** |
| 衰减**测试方法**与判定机构（第三方？厂内？现场抽测？）| 🟡 | 方法不同结论差异大 |
| **产品质保 vs 功率质保**期限是否区分（常见 12 年产品 / 25 年功率）| 🟡 | 混淆将架空索赔权 |
| 风机**可利用率保证**（如 ≥95%）及其计算口径（是否含电网原因、计划检修）| 🔴 | 口径是核心 |
| 储能：循环次数、**可用容量保持率**、往返效率（RTE）保证 | 🔴 | 当前行业纠纷高发区 |
| 储能电芯**衰减与一致性**责任、BMS 责任边界 | 🟡 | 电芯厂与系统集成商之间易推诿 |
| 逆变器/PCS、箱变、主变的质保期与**响应时限** | 🟡 | 只写"质保N年"不写响应时限，停机损失难索赔 |
| **设备原厂质保能否转让/直接对业主**（业主立场应力争）| 🟡 | 仅由 EPC 承包人背书则承包人注销后无救济 |
| 关键设备**品牌/短名单与替换规则**是否约定 | 🟡 | 缺失则承包人可低价替代 |

---

## 三、并网、涉网试验与调度

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| **并网点与接入系统方案**责任方（谁办、谁出钱）| 🔴 | 责任不清必然逾期 |
| **并网手续/电力业务许可证/并网调度协议**的办理责任方与期限 | 🔴 | 政策类依据**须查现行规定**；业主通常为主责，但 EPC 应负配合义务，须写明 |
| **涉网试验**（一次调频、SVG/AVC、低电压穿越、建模与仿真等）由谁组织实施与承担费用 | 🔴 | 未约定则费用与工期责任悬空 |
| 涉网试验**不通过**的后果：整改责任、费用、是否构成工期顺延事由 | 🔴 | 对承包人是重大敞口 |
| 并网延误导致**电费损失/补贴损失**由谁承担 | 🔴 | 金额可能远超合同额零头，必谈 |
| 送出工程（外线）由谁建设、工期与本项目如何衔接 | 🔴 | 外线未通而场内已建成是典型风险 |
| 调度自动化、功率预测系统、通信通道的责任边界 | 🟡 | 常漏项 |

## 四、电网考核与罚款的分摊（两个细则 / 辅助服务）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 并网**考核罚款**（AGC/AVC、一次调频、功率预测准确率、电压合格率等）由谁承担 | 🔴 | 政策依据**须查现行"两个细则"与辅助服务规定**；运维阶段通常由运维方承担，但建设期缺陷导致的应在 EPC 责任内 |
| 考核罚款的**责任区分机制**：设备缺陷 vs 调度指令 vs 电网原因 | 🔴 | 无区分机制则业主承担全部 |
| 考核数据来源与**争议复核程序**（以调度机构结算单为准？可否申诉）| 🟡 | 缺失则业主单方买单 |
| 辅助服务收益（调峰/调频补偿）归属 | 🟡 | 储能项目尤为重要 |

## 五、土地、屋顶与场地（分布式与集中式均适用）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 土地/屋顶**权属证明、使用权限、抵押查封状态** | 🔴 | 权属瑕疵可致项目无法并网或拆除 |
| **用地合规性**：是否涉及耕地、林地、草地、生态保护红线、压覆矿、文物 | 🔴 | 政策依据须查现行土地与林草规定；违规用地后果严重 |
| **租期与运营期匹配**（光伏 25 年、风电 20 年）及续期安排 | 🔴 | 租期短于运营期是致命缺陷 |
| 屋顶**承重、防水、结构安全鉴定**责任与费用 | 🔴 | 分布式项目高发风险 |
| 屋顶翻修、拆迁、厂方停产时的**补偿与拆除责任** | 🟡 | 缺失则业主血本无归 |
| 土地税费、青苗补偿、迁改费用由谁承担 | 🟡 | 常漏项 |
| 场区道路、施工临时用地与恢复责任 | 🟡 | |

## 六、电价、补贴与政策变动

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 上网电价机制（平价/竞价/机制电价）与**结算口径** | 🟡 | 政策依据须查现行电价文件 |

| 补贴/绿电收益**延迟或落空的损失承担** | 🟡 | |
| 电价结算账户、抄表与争议处理 | 🟡 | |

## 八、运维（含 O&M 委托时）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 运维范围、响应时限、可用率考核与罚则 | 🟡 | |
| **备品备件清单与储备责任**、停机损失是否可索赔 | 🟡 | 仅写"及时维修"无牙齿 |

## 九、工期与不可抗力（新能源特有）

| 检查点 | 风险 | 依据与说明 |
|---|---|---|
| 工期是否受**并网时序、外线建设、设备到货**制约，接口责任是否明确 | 🔴 | 发包人原因致延误的顺延与索赔：《民法典》第803、804条（**已核验**）|
| 恶劣天气、冰冻、沙尘、洪水的**工期顺延标准**（量化阈值）| 🟡 | 仅写"恶劣天气可顺延"必争议 |
| 设备（组件/风机/电芯）**涨价与供货延迟**的风险分担 | 🔴 | 长周期项目必谈；调价机制缺失是重大风险（同 01 第八节）|

## 十一、本清单的已知边界（诚实声明）

- 本清单的**政策类检查点不附条号与文号**，出具报告前必须检索官方现行文本核对。
- 新能源领域的电价、并网、绿证、辅助服务规则**修订频繁**，本清单应**每 6 个月复核一次**（同 `00-legal-basis-index.md` 第四节的复核要求）。
- 本清单未覆盖：抽水蓄能、氢能/制氢、海上风电、源网荷储一体化、虚拟电厂的专项规则——遇到这些类型时，按"检查点 + 现行政策检索"方式临时补充，不得套用本文结论。
