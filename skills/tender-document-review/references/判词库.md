# 判词库（通用扫描关键词）

> **用途**：在"第7步 穷尽性自检"前，用本表对全文做一遍关键词扫描，作为**防漏补网**。
> **性质**：本表是**线索发现工具**，不是判据。命中只代表"此处可能有条款"，**必须回到原文核对**后，才能进入清单。
> **通用性**：本表为**通用招标文件**适用，不针对任何特定项目类型。凡项目中出现的专有名词（专业术语、设备名、工艺名）不属于本表范围，由审查人在"项目专有词"中自行补充。

---

## 使用方法

1. 对全文逐词扫描，记录命中**行号/页号**；
2. 逐条回原文核对：该处**是否**构成限制性条款；
3. 核对后按七类归集（对应 SKILL.md 第4步）；
4. 扫描完毕后，在"章节覆盖对照表"中注明每章命中数（**每个章节都须列入**；无命中填 0，**不得以"已覆盖全部章节"一句代替本表**）；
5. **命中≠条款**：关键词可能出现在目录、术语解释、投标文件格式示例中，须排除。

> **免责**：本表不追求"词多即全"。招标文件的限制性条款**大量以自然语言陈述**（如"投标人应在……前完成……，否则……"），单纯靠关键词无法穷尽。本表的定位是"兜底补漏"，主要发现**明示性**否决/资格/时间/形式条款。真正的穷尽靠"逐章遍历"。

## 一、废标 / 否决类（最高优先级）

**对应类别：③ 废标/否决情形**

| 关键词 | 说明 |
|---|---|
| 废标 | 明示废标 |
| 否决 / 被否决 / 否决投标 | 评标否决 |
| 无效 / 视为无效 / 无效投标 | 无效认定 |
| 拒绝 / 将被拒绝 / 拒收 / 不予接收 | 递交阶段拒绝 |
| 不予受理 | 受理环节排除 |
| 取消投标资格 / 取消其中标资格 / 视为放弃中标 | 资格剥夺 |
| 视为串通投标 / 串通投标 | 推定情形（机器码、IP、联系电话一致等） |
| 视为提供备选方案 | 格式违规推定 |
| 视为撤回投标文件 | 逾期/违规推定 |
| 不予认可 | 材料/业绩不予认定 |
| 不予退还投标保证金 / 将不予退还 | 保证金罚没情形 |
| 得0分 / 计0分 / 不计分 | 评分归零（隐性否决） |

> 🔴 **"废标"与"否决"为同一事项的两个名称，必须并行扫描、合并归集**：文件常**通篇只用其中一个词**（实测同一批条款中"废标"0 次、"否决"17～18 次的文件），二者含义相同、无实质区别。
> - **不得**把两词当作"两种口径"做换算（如"废标=0 时改搜否决"），**不得**按两词分别设条数阈值，**不得**按文体分级设不同阈值；
> - **统计与自查时两词合并计数**；若只按"废标"一词统计，会得出"0 条、疑似漏扫"的错误结论；
> - 与"**履约保证金／履约担保**"属同一类问题（同一事项多个名称），统一按"**异名并扫**"处理。

> **易漏提醒**：
> - "**视为……**"是最高危句式——它把某客观情形直接推定为违规后果，往往不带"废标"二字，但后果等同废标。
> - 否决情形常**分散**在"投标人须知前附表""评标办法""附件"三处，须合并归集。

## 六、通用↔专用类（防"只读通用范本漏业主约定"）

**对应类别：⑤ 商务条款 + ⑥ 合同关键约束（铁律10）**

> ⚠️ **先锁定术语再扫词（否则必然零命中）**：施工类用「**条款**」，总承包 GF-2020-0216 用「**条件**」。下表两套术语**都要扫**，取命中数多者为本轮用语。实测频率：条件式主导的文件中，"除专用合同**条件**另有约定外"命中 **71 次**量级，而"合同**条款**"全篇仅 2～3 次（且均为引用性提及）。

| 关键词 | 说明 |
|---|---|
| **除专用合同条款另有约定外** | **长式**（GF-2017-0201 施工类）；每出现一次＝该条有业主版本，必跳专用部分核对。10 份实测样本中 6 份属此型，典型命中 27～68 次 |
| **除专用合同条件另有约定外** | **条件式**（GF-2020-0216 总承包 EPC/EPCO）；实测命中可达 55～71 次 |
| **除专用条款另有约定外** | ⚠️ **短式（最易漏，务必单列）**：不带"合同"二字。实测短式:长式 = 116:12 与 121:6 两例，**只搜长式会漏 90.6%～95.3% 的指针句**（漏失率＝短式÷两式之和，可复算） |
| **除合同条款另有约定外** | 另一短式变体（偶尔出现） |
| **在专用合同{条款/条件}中约定 / 按专用合同{条款/条件}约定 / 专用合同{条款/条件}约定为 / 专用条款另有约定** | 同类指针句，**四套写法都要扫** |
| **第一节 通用合同条款 / 第二节 专用合同条款** | 施工类 GF-2017-0201 两节结构（定位用） |
| **第一部分 合同协议书 / 第二部分 通用合同条件 / 第三部分 专用合同条件** | **总承包类三部分结构**（⚠️ 术语与上一条完全不同，不得混用） |
| 🔴 **第三章 合同条件 / 第四章 合同条款及格式 / 合同条件 / 合同条款 / 合同协议书 / 安全文明施工协议** | **第四种形态（无通用/专用之分，三组标准词必然全 0）**：合同章全章单列，**章下直接分节**（或按"1.合同协议书 / 2.××协议"排列），**无"通用/专用"字样、无指针句**。章名实测有三种表现：「**合同条件**」「**合同条款及格式**」「**合同协议书**」。该形态下"合同条件／合同条款／合同协议书"裸词仅个位数命中，而**三组标准词命中全部为 0**（两种独立解析器复核一致）。→ 遇此形态**不做"通用↔专用比对"**，改为**按 ⑤⑥ 两类字段归档提取**并注明"本文件合同章未作通用/专用分节" |
| 🔴 **本合同不执行通用第N条……条款 / 本合同不适用通用……条款** | **反向形式（非填空、非改写）**：专用部分**明示排除**通用某条。须单列并注明"通用第N条经专用部分明示排除，本文件不适用"，**不得当作"未改写"略过** |
| 合同价格 / 签约合同价 / 价格调整 / 物价波动 / 调价 | 价格类（专用条款常改写） |
| 预付款 / 预付款比例 / 预付款扣回 / 进度付款 / 进度款 | 付款类（专用条款常填空） |
| 结算 / 竣工结算 / 结算周期 / 付款周期 | 结算类 |
| 逾期竣工违约金 / 违约金 / 最高限额 / 罚款 | 违约类（专用条款常填数值） |
| 缺陷责任期 / 保修期 / 质量保证金 / 质保金 / 质量保修金 | 质保类（专用条款常改起算点与比例） |
| 保险 / 投保 / 保险金额 / 保险范围 | 保险类 |
| 🔴 **履约保证金 ／ 履约担保 ／ 履约保函**（同一事项的三个名称，**必须并行扫描**）/ 担保金额 | 担保类：文件常只用其一，或**多名称并存且取值不同**。只按"履约保证金"扫描会整类漏掉；**"履约保函"常仅出现在合同章正文内**（如"乙方须向甲方提供合同总价 5% 的履约保函"），不含前两名，须单独并入搜索词。多值并存时须逐条列出各值与各自出处 |
| 🔴 **运维保证金 / 农民工工资保证金 / 支付担保 / 预付款担保 / 低价风险担保** | **其他专项保证金（漏项高发区）**：与上表各类**不同名**，只按"投标/履约"二分扫描会**整类漏掉**。做法：全文搜"保证金/担保"通用词，对每处命中**逐个判定归属** |
| 🔴 **保证金（裸词全扫）＋ 除前附表另有规定外 / 除投标人须知前附表另有规定外** | **保证金"前附表值 ↔ 正文默认值"对照**：正文范本常写"除前附表另有规定外为 X%"，前附表实填另一值，**以前附表为准，两值均须列出并给出处**。实测该双值不一致确有出现（两值为不同比例，须两值并列给出处） |
| 分包 / 转包 / 指定分包 / 甲指分包 | 分包类（专用条款常设限） |
| 暂列金额 / 暂估价 / 计日工 | 暂列类（易与限价矛盾，注意笔误） |
| 发包人 / 承包人 / 监理人（专用条款中出现的具体约定） | 主体约定 |
| 争议解决 / 仲裁 / 诉讼 / 管辖 | 争议类（专用条款常改管辖地） |

> **易漏提醒**：
> - 通用部分看似完整，**其生效版本在专用部分**——这是"读完通用就以为齐了"的最大陷阱。
> - 指针句出现频率是**判断业主改写规模的温度计**；命中越多，专用部分越要多花时间。
> - 专用部分中**独立成条**（通用无对应）的约定，是业主**自行增加**的条款，最易漏，须单独收录。
> - 🔴 **零命中警报**：若指针句一套都没命中，**严禁直接写"无改写项"**。先查四项：①分节是否找对（总承包是"第一/二/三部分"不是"第几章第几节"）；②术语是否错位（条款↔条件↔短式）；③专用内容是否已并入正文不再单列；④🔴 **是否属"无通用/专用之分"形态**（章名仅称"合同条件／合同条款及格式／合同协议书"，章下直接分节，三组标准词必然全 0）——此为实测最常见的零命中成因之一。该形态下**按 ⑤⑥ 两类字段归档提取**，并注明"本文件合同章未作通用/专用分节"。
> - 🔴 **结构可自由组合**：「分节方式」与「术语体系」**不绑定**——实测存在"**部分式结构 ＋ 短式术语**"的组合文件。两项**分别判、分别记**，不得因结构像施工类就预设长式术语，也不得因术语是短式就预设无分节。
> - 🔴 **业态适配（服务业态）**：运维／检修／物业／咨询等**服务类**业态下，工期、缺陷责任期、质量保证金、预付款、保修期等子项**天然不存在**，须标"**本业态无此项**"，**严禁填"未找到"或"文件未载明"**。实测：服务业态文件的 ⑤ 类命中种类数降至 4 种（工期／缺陷责任／预付款均为 0），工程业态为 6～7 种。
> - 🔴 **PDF 文本层破损（不限于扫描件）**：①**版面换行断裂**——标签与数值被版面切成上下两行（如"金额为："与"12万元"分处两行），凡行内匹配关键词＋数值的扫法必然整条漏掉，须**先跨行拼接再匹配**；②**局部编码损坏**——文本层出现乱码段，该段所在条款须标"文本层损坏，需回原件核对"。
> - 🔴 **体系线索词歧义**："**政府采购**"常以「**政府采购**严重违法失信行为记录名单」的形式出现，属**失信名单名称**（位于资格否决条款内），**不是发布主体线索**；"采购人""交易中心"亦须核对其邻近上下文。**见词即录会导致体系线索报错。**
> - 🔴 **递交形态判定须先做语义归类，不得按词频直接定形态**：命中的"密封/纸质/上传/解密"等词须逐处回原文归入四类——**①投标文件载体**（计入形态）／**②保证金载体**（如"纸质保函原件须密封送达开标现场"）／**③中标后归档**（"中标后补交 2 份纸质件"）／**④无关词义**（营业执照副本、格式示例）。**只有 ① 类计入形态判定**；② 类须**单列一行**（其后果常为废标级），③④ 类不计入。
> - 🔴 **服务类业态缺服务侧约束**：⑥ 类字段原为工程视角，服务业态另须提取"**服务考核与扣款**"——考核周期、考核指标、扣款比例与机制、服务侧违约责任、SLA/服务标准（常独立成节）。确无则标"本业态无此项"。

> **🔴 递交形态分流（扫描前必判，两套要求互斥）**：本类关键词中"密封/装订/正副本"与"CA/加密/解密/上传"**分属纸质标与电子标，通常不会同时适用**。扫描前先并行搜 A 组（全流程电子/电子招投标/网络递交/CA/加密/解密/上传）与 B 组（纸质/正本/副本/装订/密封/现场递交），取命中高者定形态，不适用的一组须在清单中标注"不适用"及理由。
> 实测：纯电子标（密封 0、解密 10）与纯纸质标（密封 9、正副本 39、CA 与解密均 0）呈互斥分布；🔴 **但实测存在两组均显著的文件**，须按混合态两组全部逐项提取，**不得二选一**。**CA 办理常需提前数日，形态判错即致命。**
> ⚠️ 签章、投标人代表（人脸识别/到场）、暗标格式、澄清答复程序、原件核验**五项恒扫，不随形态分流**。

> **🔴 暗标属"高风险、命中率波动大"项——须先判语境，且不得只报"低概率"**：
> **语境二分（不得见词即展开 8 项）**：
> - **① 本项目采用暗标**：文件以独立条款/专章规定暗标**编制格式要求** → 展开 8 项专项；
> - **② 暗标仅在否决条款中被引用**：仅出现在"**招标文件规定技术投标文件采用暗标时，其出现投标人名称……即否决**"这类**假设条件句**中，属通用性否决条款 → **只记语境＋出处，不展开**，并写明"**本文件未采用暗标编制要求**"。
>   实测：某文件全文"暗标"仅 2 处、**全属语境②**；机械展开会产出 8 行伪"未载明"，掩盖真实事实。
>
> **频率（两口径须分别标明）**：含公告与询价书的 13 份中 **1 份**出现；另一轮 5 份中**字样出现 3 份、真实采用 2 份**。⚠️ **不得只写"低概率"**——该表述会误导执行者放松警惕，与"不得略过"的本意相悖；应表述为"**高风险、命中率波动大**"。
> 见到"横向暗标/技术文件不设目录/不得出现单位名称、地址、人员姓名、清晰人像、单位图标、签字盖章/技术文件部分不得签章/**各评审因素章节页面数量上限**"等，须**逐项提取具体数值**并单列。
> - **后果必须照录文件明示的选择**：文件常以勾选式给出后果（如"格式、制作、页面数量不符合要求的，按照 ☑**扣分**处理，☐**否决投标**处理"），实测到**选扣分而非否决**的情形——凭印象写成"直接废标"即属加工推演。
> - ⚠️ "**是否接受澄清、说明或补正**"**不是暗标格式要素**：实测暗标条款周边此表述出现 **0 次**，它实为**独立废标条件**，应归入①类澄清答复程序或③类废标条件。
