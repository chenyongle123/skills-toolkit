# 投标核对清单模板（七类）

> 本文件定义七类清单的**字段结构与填写规范**。使用时按此结构成表，字段不得缺省。

---

## 🔴 填表前置判定（三项，未完成不得进入七类填表）

| 判定项 | 目的 | 落到何处 |
|---|---|---|
| **① 文件来源类型**（招标／询价比选／竞争性谈判磋商／单一来源议标框架协议／**央企国企自采程序文件**） | 防"套用招标口径产出伪无" | 见 SKILL.md 第 2 步。**央企/国企自采仅照录分类标签＋识别依据，不据此调整提取口径** |
| **② 业态**（工程／货物／**服务**） | 服务业态下工期、缺陷责任期、质量保证金、预付款、保修期等项**天然不存在**，须标"**本业态无此项**"——**严禁填"未找到"或"文件未载明"** | 七类各表相应行 |
| **③ 递交形态**（纯电子／纯纸质／混合／**电子标＋纸质载体保证金**） | 防两套互斥要求同时填表；**判定须先做四类语义归类，不得按词频直接定形态** | ⑦ 类判定框 |

> 🔴 **PDF 文本层破损（不限于扫描件，文字型 PDF 同样会破损）**
> - **版面换行断裂**：标签与数值被版面切成上下两行（如"金额为："与"12万元"分处两行）→ **须先跨行拼接再匹配**，否则整条漏掉；
> - **局部编码损坏**：文本层出现乱码段 → 该段所在条款标注"**文本层损坏，需回原件核对**"。
> - 凡涉及金额、比例、期限、天数等精确数值，**必须回原文页核对**，不得直接采信提取值。
>
> 🔴 **体系线索词歧义**：填【适用体系线索摘录表】前须回原文核对邻近上下文——"**政府采购**"常以「**政府采购**严重违法失信行为记录名单」出现，属**失信名单名称**（位于资格否决条款内），**不是发布主体线索**；见词即录会导致体系线索报错。

## 通用字段规范

每张表统一采用以下列：

| 列名 | 说明 | 必填 |
|---|---|---|
| 序号 | 条目编号（按类内顺序） | 是 |
| 事项 | 条款主题（如"项目经理资格"） | 是 |
| 原文要求 | 摘录/转述原文要求，不得改写原意 | 是 |
| 出处 | 页号 + 条款号 + 行号（扫描件：页号+条款号+首句） | 是 |
| 备注 | 是否被澄清修订、以何者为准、是否关注性条款 | 是 |

## ⑤ 履约保证金与商务条款

> **铁律9**：本类只放**履约保证金**（中标后/合同环节）；**投标保证金在①-附加**。
> 🔴 **本类须以「履约保证金」「履约担保」「履约保函」三个名称并行扫描**：文件常只用其一，或多名称并存且取值不同；**"履约保函"常仅见于合同章正文内**，只扫前两名会漏掉；只扫"履约保证金"会整类漏掉。
> **铁律10**：本类中凡通用部分写"按专用部分约定"的项（**术语按铁律10 锁定**，可能是「条款」也可能是「条件」），**必须取专用部分业主实际值**。
> 🔴 **"前附表值 ↔ 正文默认值"双值对照**：履约担保/保证金常出现正文写"除前附表另有规定外为 X%"、前附表实填另一值，**以前附表为准，两值并列给出处**（实测该双值不一致确有出现）。

## ⑥-附 通用↔专用改写项比对表（**铁律10 必做交付物**）

> **表名随术语**：施工类题"专用合同条款改写项比对表"；总承包 GF-2020-0216 类题"专用合同条件改写项比对表"。
> 本表专用于把"通用范本 → 专用部分业主改写"的变化显性化。**只列改写/填空/新增三类，未改的不列。**

| 序号 | 条款号 | 通用部分默认表述（摘要） | 专用部分业主实际约定（全文） | 变更类型 | 出处（专用部分行号） |
|---|---|---|---|---|---|
| | | | | 改写／填空／新增 | |

> **术语提示**：总承包类文件中上述"条款"位置均作"**条件**"（通用合同条件 / 专用合同条件），请按本项目实际用语填写表头。
> **完成判定**：通用部分中"除专用部分另有约定外"等指针句（常 50+ 处，**总承包类写作"除专用合同条件另有约定外"**），须逐条核对已否落入本表；本表未成，不得宣告 ⑤⑥ 完成。
> 🔴 **零命中警报**：指针句一套都没命中时，**严禁直接写"无改写项"**，须先按铁律10 完成**四项**核验：①分节是否正确；②术语是否错位（条款／条件／短式／**无通用/专用之分**）；③专用是否已并入正文；④🔴 **是否属"无通用/专用之分"形态**（章名仅称「合同条件」／「合同条款及格式」／「合同协议书」，**章下直接分节**，三组标准词必然全 0，此为实测最常见成因）。
> 若判定为第 ④ 种：本表改为"**按 ⑤⑥ 两类字段归档提取**"，并在表名后注明"**本文件合同章未作通用/专用分节**"。
> 🔴 **结构×术语可自由组合**：「分节方式」与「术语体系」**不绑定**——实测存在"**部分式结构（第一部分合同协议书／第二部分通用条款／第三部分专用条款）＋短式术语（专用条款）**"的组合文件。两项**分别判、分别记**，不得因结构像施工类就预设长式术语，也不得因术语是短式就预设无分节。
> 🔴 **另须逐条排查反向形式**：专用部分直书"**本合同不执行通用第 N 条……条款**"者，变更类型标"**明示排除**"并单列，不得当作"未改写"略过。

## ⑦ 形式与程序要求（最大废标源）

> 🔴 **填表前置：先判定"递交形态"，再决定本表哪些行填、哪些行标"不适用"**
> 招标文件只可能属下列形态之一，"装订密封"与"CA 加密解密"**通常互斥**，两套要求同时填表会让用户照做即出错（**CA 办理常需提前数日，漏判即致命**）。
> 🔴 **判定方法：先做四类语义归类，不得按词频直接定形态**——并行搜 A 组（全流程电子/电子招投标/网络递交/CA/加密/解密/上传）与 B 组（纸质/正本/副本/装订/密封/现场递交），**对每处命中回原文归入**：**①投标文件载体**（✅计入形态）／**②保证金载体**（如"纸质保函原件须密封送达开标现场"，❌不计入但**须单列一行**）／**③中标后归档**（"中标后补交 2 份纸质件"，❌不计入）／**④无关词义**（营业执照副本、格式示例，❌不计入）。**再以 ① 类计数定形态**。
> 请在下框填写判定结果：**本文件递交形态 = □纯电子标　□纯纸质标　□混合态　□电子标＋纸质载体保证金**（判定依据：________；语义归类结果：①__项 ②__项 ③__项 ④__项）
> - **纯电子标** → 装订、密封与标识、正副本份数、现场递交 四行填"**不适用（全流程电子）**"
> - **纯纸质标** → CA 锁/加密解密、远程在线/解密时限 两行填"**不适用（纸质递交）**"
> - **混合态** → 全部逐项提取
> - 🔴 **电子标＋纸质载体保证金** → 投标文件各项按纯电子标处理，**并必填下方"保证金载体递交形式"行**
> ⚠️ **签章、原件核验、澄清答复程序、投标人代表、暗标格式 五行恒填，不随形态分流。**

|---|---|---|---|---|
| | 🔴 **保证金载体递交形式**（**恒填**） | | | □电子保函 □**纸质原件（须单独密封＋送至开标现场，截止：__）** □其他。**照录文件明示后果**（实测"未在规定时间递交原件＝视为未提供投标保证金"＝废标级） |
| | 投标文件组成与顺序 | | | 注明触发废标的具体动作 |
| | 目录、页码、装订、密封 | | | 纯电子标填"不适用" |
| | 份数、签章/盖章位置 | | | **签章为形式废标第一来源** |
| | **签章细节** | | | **逐页签字/逐页盖章/骑缝章/封面盖章/法定代表人签字位置/授权委托人签字效力/CA 电子签章位置** |
| | **原件核验** | | | **复印件是否须与原件一致、是否需携带原件备查** |
