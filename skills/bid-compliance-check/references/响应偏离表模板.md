# 响应偏离表模板与填法（②-A/②-B · B 类）

> **依据**：计划书 §4.3 B 类、F3（禁照抄原文/正偏离注明/不允许负偏离=出局）、计划书 §6.2 `01b` 字段定义。
> **行来源**：`01b_spec-items.json` 逐行——**行数须与规范表逐行一致**（合并单元格拆多行、跨页同表连续计数不重置、并列项计多项）。`01b` 未齐备前，逐行一致性检查挂起（验收记录 #5 口径），不得用 2 条代表项冒充全覆盖。
> **人工填写落点（v0.4.0 契约）**：`08_business/deviation-table.md`——人工按本模板填写，② 只读不代填（计划书 §5.1：08_business 为人工填写区，Skill 只读）；填写完成后再跑 `check_compliance.py --mode B` 逐行核验。

## 一、表结构（每行对应 `01b` 一条，首列为 01b 主键）

| 列 | 来源 | 规则 |
|---|---|---|
| 条目id | `01b[].id` | **sp-xxx 主键，照录**（机检对行依据：跳条/多行/重行判定全靠此列） |
| 条款号 | `01b[].clause` | 照录，**不重排** |
| 要求项 | `01b[].requirement` | 照录 |
| 招标要求值 | `01b[].required_value` | 照录（含 ≥ ≤ 符号），**不换算** |
| 单位 | `01b[].unit` | 照录 |
| 响应值 | **投标人实际值** | **禁止照抄招标原文**——照抄=无法证明真实匹配，按未响应 |
| 偏离判定 | 派生 | `正偏离 / 负偏离 / 无偏离` 三值；优于要求注明「正偏离」**并给具体内容** |
| 不允许负偏离 | `01b[].no_negative_allowed` | true 时出现负偏离＝**废标级**，单列红色提示 |
| 出处 | 成稿定位 | 章节+段落（铁律 7：每段可回溯） |

## 二、填法铁则

1. **响应值填自身实际指标**：来自 `02_facts` 或用户明示；未见于事实库写 `【待填：××】`，**不得由 AI 推算**（铁律 1）；
2. **正偏离须具体**：「优于要求」必须给出具体数值/内容，不得只写"优于招标要求"；
3. **负偏离分级**：`no_negative_allowed = true` 的条款，任何负偏离即出局——② 只报事实态，不替投标人决策是否放弃该条款（铁律 5）；
4. **不合并、不跳条**：`01b` 有多少行，偏离表就有多少行；连续同值条款可合并**表述**但不得合并**行**；
5. **空白不等于无偏离**：无偏离须显式写「无偏离」或「无」，留空按未响应处理。

## 三、②-A / ②-B 分工

| 段 | 查什么 |
|---|---|
| ②-A | 行数与 `01b` 是否一致、有无合并/跳条、`no_negative_allowed` 标记是否传递到偏离表 |
| ②-B | 逐条填响应值判偏离；响应栏与事实库一致性（数值不得超事实库承载） |

## 四、输出

- ②-A：`06_compliance/deviation-table.md`（B 类节，行数核对结论 + 差异清单）；
- ②-B：`06_compliance/deviation-table.md`（逐条偏离判定 + 废标级负偏离单列；输入＝`08_business/deviation-table.md` 人工填写版，机检项：跳条/多行/重行/照抄/空白判定/负偏离分级/出处断链）。

> ⚠️ **② 不算价、不改写**：报价类偏离（如总价、分项价）只查"是否填报、是否跨章一致"，不算总价、不评合理性。
