# 判词库-投标侧（漏响应扫描关键词）

> **派生自**：⓪ `tender-document-review` v1.5.0 之 `references/判词库.md`（同步日期 2026-10-18）。
> 派生规则（计划书 §3.5 三类复用）：**只取签章/暗标/废标词条，加投标侧补充词，不复制整份**。
> **用途**：②-A/②-B 检查前，用本表对**投标文件成稿**做一遍关键词扫描，作为**防漏响应补网**——线索发现工具，不是判据；命中只代表"此处应有响应"，必须回 `01`/`01b`/`01c` 与任务卡核对后才能下"未响应"结论。
> **性质**：② **不读招标原文**（计划书 §3.2 边界）。本表的用法是拿**任务卡的响应要求**（来自 ⓪ v1.5.0 的七类清单）去**投标文件**里找落点，而不是拿原文直接比对。

---

## 使用方法

1. 对投标文件全文（`05_chapters/*.md` 与装配稿）逐词扫描，记录命中**章节/段落定位**；
2. 逐条回 `03_bid-plan.json` 核对：该处**是否**对应某任务卡的响应落点；
3. 命中但无对应落点 → 记"疑似漏响应"，**回原文核对**该条是否构成响应（如目录、术语解释中的命中须排除）；
4. **章节覆盖对照**：`01` 七类逐类过一遍，**每个类别都须列入**，无命中填"已全覆盖"，不得以一句"无遗漏"代替（⓪ 判词库"穷尽性不得自证"同款规则）；
5. **命中≠响应**：关键词出现在格式示例、模板套话、目录中时，不构成真实响应。

## 一、废标/否决响应词（对应 ⓪ ③ 类，最高优先级）

| 关键词 | 扫描目的 |
|---|---|
| 否决 / 废标 / 无效投标 / 视为 | 成稿中**不应出现**自认式表述（如"如不满足则否决"照抄进响应正文）；任务卡须有对应响应动作 |
| 串通投标 / 围标 | 响应文件不得含雷同模板痕迹（转 E 类） |
| 备选方案 | 不得擅自提供备选（除招标明确允许） |
| 撤回 / 放弃 | 中标后承诺类条款的响应位置 |
| 不予退还 | 保证金条款响应位置 |

## 二、资格响应词（对应 ⓪ ② 类）

| 关键词 | 扫描目的 |
|---|---|
| 资质 / 资质等级 / 证书编号 | 响应位置与 `02_facts` 记录一致（**数值以事实库为准**，素材不得改写） |
| 业绩 / 类似业绩 | 业绩表是否填**自身实际**业绩（禁照抄招标要求） |
| 项目负责人 / 项目经理 / 注册建造师 | 人员配置响应与事实库一致 |
| 社保 / 审计报告 / 资信 | 财务与社保材料齐备位 |
| 联合体 / 分包 | 联合体协议/分包情况表是否按实际填写 |
| 关联企业 / 控股 / 管理关系 | 排除声明是否出具（对应 ⓪ c-0013 类条款） |

## 三、评分点响应词（对应 ⓪ ④ 类）

| 关键词 | 扫描目的 |
|---|---|
| 评分 / 分值 / 得分 | 每个评分点在 `04_outline.json` 有落点（`scoring_refs` 非空） |
| 偏离 / 响应 / 实质性响应 | 偏离表存在且**不合并、不跳条**（转 B 类） |
| 正偏离 / 负偏离 / 无偏差 | 优于要求须注明「正偏离」并给具体内容；**不允许负偏离的条款出现负偏离＝出局** |
| 加分 / 加分项 | 加分项的证明材料齐备位 |

## 四、形式响应词（对应 ⓪ ⑦ 类 + ⓪ 判词库第五类）

| 关键词 | 扫描目的 |
|---|---|
| 盖章 / 签字 / 签章 / 骑缝 / 逐页 | 签章位齐备（`01c.typography.seal`），扫描件签章位置正确 |
| 份数 / 正本 / 副本 | 份数符合 `binding`/格式章要求 |
| 密封 / 装订 | 装订方式响应（纸质标） |
| CA / 加密 / 解密 | 电子标加密解密流程响应位 |
| 授权委托书 / 委托代理人 | 授权签字链条完整（法人→代理人） |
| 人脸识别 / 到场 / 身份核验 | 开标环节人员安排响应（如招标要求） |
| 原件 / 复印件 | 材料形式与"需原件核对"标记一致 |

## 五、暗标匿名词（对应 ⓪ ⑦ 类暗标格式；仅 `bid_mode=blind` 展开）

| 关键词 | 扫描目的 |
|---|---|
| 单位名称 / 公司名 / LOGO / 图标 | 成稿**任何位置**不得出现（含页眉页脚、图表题注、文件属性） |
| 人员姓名 / 项目经理姓名 | 匿名化处理（以岗位代称） |
| 字体 / 字号 / 行距 / 页边距 | 与 `01c.typography` 8 字段逐项一致（计划书 §11.2 第 8 条验收口径） |
| 页数 / 页面数量 | 不超 `page_limit`（含证据页） |

> ⚠️ **先判语境**：仅当上游判定"语境①本项目采用暗标"时展开本节；语境②（暗标仅出现在否决条款）不得按暗标成稿要求扫描。

## 六、投标侧补充词（⓪ 判词库没有、② 特有）

| 关键词/检查 | 扫描目的 |
|---|---|
| 【待填：××】/【待确认： | **成稿终检必须清零**——占位符残留即未完成（铁律 1） |
| 无 | 「无偏差」须**显式注「无」**，不得留空（bf-05/bf-19 专项） |
| 照抄 | 响应栏与招标原文逐字相同的段落——按未响应（计划书 §4.3 B 类） |
| 暂定 / 待定 / 以实际为准 | 模糊承诺信号，回任务卡核对是否应为确定值 |
| 万元 / 元 / ¥ | 金额出现位：**② 不算价**，只查跨章一致性（同一金额各处相同） |
| 工期 / 交货期 / 日期 | 跨章日期/工期数字一致性（转 C 类） |
| 第 X 章 / 第 X 节 | 交叉引用位置与实际章节号一致（引用错位=形式缺陷） |
