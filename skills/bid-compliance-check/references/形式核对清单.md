# 形式核对清单（②-A/②-B · C 类）

> **依据**：计划书 §4.3 C 类、计划书 §11.2 第 8 条（暗标 8 字段口径）；② SKILL.md §一"形式要求取自已授权产物"表。
> **口径**：② **不读招标原文**。形式要求一律取 `01c.typography`（`seal`/`binding`/`page_limit`）与 `01.clauses[]` 中 `review_stage = form` 条目；字段缺失判 `blocked_by_contract` 指回 ①。

## 一、形式要求来源对照

| 形式要求 | 取自 | 缺失处理 |
|---|---|---|
| 签章位、份数、装订方式 | `01c.typography.seal` / `binding` | 指回 ① 补抽 |
| 页数上限 | `01c.typography.page_limit` | 未载明（null）时：②-A 报信息态，交人工按招标隐含要求估算并**写明依据**，不得静默放行 |
| 身份标识禁项 | `01c.typography.identity_ban` | 暗标项目终检必查 |
| 形式类废标条款 | `01.clauses[]` 中 `review_stage = form` | 清单缺失指回 ① |

## 二、②-A 查（任务卡/目录骨架层面）

- [ ] 暗标 `bid_mode` 从 `00_metadata` 正确传递到任务卡与目录骨架；
- [ ] `binding`/`seal` 字段齐备（非空串）；
- [ ] 页数预算可行：任务卡 `word_target` 合计与 `page_limit` 的量级关系（信息态报出，不阻断）；
- [ ] 形式类废标条款（form）在任务卡有覆盖（与 A 类主覆盖同表）。

## 三、②-B 查（成稿层面，阶段 2）

- [ ] 签章位与 `seal` 一致（骑缝/逐页/法人签字等逐项核）；
- [ ] 份数、装订方式符合 `binding`；
- [ ] **无论是否暗标**，正文+证据总页数不超 `page_limit`；
- [ ] 电子标：CA/加密/解密流程响应位齐备；
- [ ] 暗标项目：按 `references/暗标匿名检查.md` 展开 8 项终检。

## 四、跨章一致性（②-B，阶段 2；转 C 类一致性子项）

跨章数字/名称/工期/金额一致性由 ②-B 检查，执行单元为 `scripts/check_consistency.py`（全套件唯一实现，①③ 不复制）。② 只报"不一致出现在哪几处、值分别是多少"，**不替投标人选定正确值**。

## 五、输出

- ②-A：`06_compliance/form-check.md`（字段齐备性 + 信息态事项）；
- ②-B：`06_compliance/form-check.md` 续写签章/份数/页数/暗标终检结论；跨章不一致写入 `consistency-issues.md`（阶段 2）。
