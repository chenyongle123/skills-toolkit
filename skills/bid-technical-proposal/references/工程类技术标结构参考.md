# 工程类技术标结构参考（仅内容组织参考）

> 版本：0.1.0（阶段 2）｜依据：计划书 §4.2（M3 目录骨架排序优先级第 3 位）
> **定位声明：本文件只是"内容组织逻辑"的参考，不是章节名的来源。**章节名与顺序一律取自 `01c_format-outline.json`（铁律 2）；两者冲突时，本文件让位——为凑参考结构改动招标规定的章节名即反例 2，格式废标优先于得分优化。

---

## 一、内容组织优先级（§4.2，不可颠倒）

1. 招标"投标文件格式"章的章节名与顺序（`01c`，逐字）；
2. 评分办法的评分项顺序（得分优化，落点记 `04_outline.scoring_refs`／`notes`）；
3. 通用技术标组织逻辑（**仅本文件**，作段落与素材编排参考）。

## 二、工程类技术标常用组织逻辑（参考）

| 块 | 常见内容 | 对应素材类型（02b tags 建议） |
|---|---|---|
| 编制依据与响应总述 | 编制依据清单、总体响应承诺 | 规范响应类 |
| 工程概况与特点分析 | 场址/规模/工期/地质气象特点、重难点识别 | 项目理解类 |
| 施工部署与总体安排 | 组织机构、施工区段划分、总体流程 | 部署类 |
| 施工进度计划与工期保障 | 里程碑、关键线路、赶工与保障措施 | 进度类 |
| 资源配置 | 劳动力、机具、材料、检验试验计划 | 资源类 |
| 主要施工方案与技术措施 | 分部分项方案、专项工艺（技术标核心） | 工艺/方案类 |
| 质量管理体系与保证措施 | 质量目标、体系、工序控制、检验验收 | 质量类 |
| 安全文明施工与 HSE | 危大工程清单、专项安全措施、应急 | 安全类 |
| 绿色施工与环境保护 | 环保措施、节水节材 | 环保类 |
| 季节性施工措施 | 冬雨季/大风/高温 | 季节施工类 |
| 竣工试验、验收与移交 | 竣工资料、消缺、移交安排 | 验收类 |
| 售后服务与质保承诺 | 质保期、响应时效（须有事实/授权来源） | 服务类 |

> 新能源 EPC 常见扩展：设计管理（勘察设计协同）、设备监造与到货管理、并网调试与试运行、智慧工地。按招标行业特点取舍，**不得凭空造章**。

## 三、评分点落点习惯（编排参考，落点真源是任务卡）

| 评分点类型 | 常见落点 |
|---|---|
| 施工/技术方案水平 | 主要施工方案与技术措施（核心章，重点篇幅） |
| 组织机构与人员配置 | 施工部署（组织机构表须与 `02_facts` 人员逐字一致） |
| 进度与工期保障 | 进度计划与工期保障 |
| 质量/安全/环保 | 对应管理章（评分细则逐条对应，勿漏 `[[S:…]]` 标注） |
| 业绩/资质/财务 | **不落技术标**（属商务/资格部分；③ 不代写，见 SKILL.md §一 不做清单） |

## 四、写作顺序建议

1. 先写**分值最高、技术含量最高**的核心章（常见为施工组织设计/主要施工方案）——先过 G4，锁定技术路线；
2. 后写通用管理章（质量/安全等），此时核心章的机具、人力、工期数据已定，管理章引用不失据；
3. `04_outline.depends_on` 标注的依赖关系优先于本建议（节点级依赖是 ① 经 G1 确认的）。

## 五、常见错误对照

- 改章节名/顺序凑参考结构 → 反例 2（铁律 2）；
- 管理章通用套话连篇、核心章反而单薄 → `写作规范.md` §一/§六 + §4.2 篇幅权重；
- 把业绩资质写进技术标响应评分点 → 越界（归商务/资格），且暗标项目下暴露身份信息（`暗标写作规范.md`）。
