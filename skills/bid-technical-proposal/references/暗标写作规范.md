# 暗标写作规范（bid_mode = blind 时的正文层叠加规则）

> 版本：0.1.0（阶段 2）｜依据：计划书 铁律 3、§6.2（01c.typography 八字段）、§11.2 第 8 条（暗标 8 字段验收）
> 触发条件：`00_metadata.json` 的 `bid_mode = blind`（③ 只读不改）。普通标（normal）不适用本文件。
> 本文件管**写作层**；样式落地（字体/字号/行距/页边距/页码）归 ④ `build_style_profile.py`；元数据清理归 ④ `scrub_metadata.py`＋`verify_docx.py`。

---

## 一、身份禁项（对照 `01c.typography.identity_ban` 逐项执行）

上游八字段中的 `identity_ban` 列出禁项清单（常见：单位名称/人员姓名/单位图标/签字盖章）。写作层执行口径：

| 禁项 | 写作层执行 |
|---|---|
| 单位名称 | 全文用中性称谓："投标人/本单位/我方"；**全称、简称、曾用名一律不得出现** |
| 人员姓名 | 一律岗位称谓（"项目经理/技术负责人"），不写姓名——含组织机构表、证书引用段 |
| 单位图标/LOGO | 正文不插图载标识；图片须为纯技术示意（见 `图表与题注规范.md` 源文件要求） |
| 签字盖章 | 正文不设签字/盖章位（模板里的盖章位属商务格式章，不归 ③ 生成） |

**灰色地带处置**：业绩项目名能否写、专利/软著名称是否指向单位等，招标文件未明说时 → 输出 `【待确认：暗标业绩表述口径】`，交人工按评标办法裁定；**不得自行放宽**（暗标判定权在评标委员会，铁律 4 同理）。

## 二、页数预算（铁律 3：无论是否暗标都管）

- 判据 = **正文 + 证据总页数** ≤ `01c.typography.page_limit`（未载明时按招标隐含要求估算并写明依据）；
- 写作层动作：`scripts/word_count.py` 控制字数（页数在 ④ 装配五项检查才精确核算，写作期按字数预算留余量）；
- 暗标通常另附页数上限，`scope = technical_only` 时只技术部分受限——以 `01c.typography.scope` 判定适用范围，不得扩大到全卷。

## 三、写作层不留可识别痕迹

1. **禁自定义样式痕迹**：不用艺术字、文本框、彩色标题、自定义题头口号；标题层级用规范编号（`图表与题注规范.md`）；
2. **禁独有表述**：企业内部惯用缩写、内部体系文件名、自编口号不得出现（可反查身份）；
3. **文档属性**：写作层产出的 Markdown 不含作者信息；docx 属性残留由 ④ 统一清理与回读校验（§8.6.3）；
4. **图片元数据**：插图源文件（`05_chapters/assets/`）含 EXIF/作者字段时先人工清理再引用，④ 装配时不再二次处理图片元数据。

## 四、每章自查（步 4 完稿后、交复核前）

1. 全文检索单位全称/简称/曾用名（按 `01c`/招标公告已知口径）、项目班子成员姓名 → 0 命中；
2. 中性称谓抽查：机构表、证书段、业绩段三类段落必查；
3. `check_facts.py` 正常通过后，暗标章额外过一遍本文件 §一 表格逐行；
4. 复检责任：②-B C 类（暗标匿名检查）与 ④ 导出前复扫是后置防线，**写作层自查先行**，不得依赖后置兜底（`references/常见错误.md` 反例 3）。
