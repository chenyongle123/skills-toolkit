# 样式与编号规范（④ 导出侧）

> **依据**：计划书 §8.2（通用基线）、§8.3（暗标叠加层）、§8.5（装配与页数）、§8.6（清洁）；
> 本文只定**导出侧**的样式档位与编号规则，写作侧排版约束见 ③ `references/写作规范.md`。

## 一、三档样式档（优先级从高到低，档内空项回落下一档）

| 档 | 触发条件 | 参数来源 |
|---|---|---|
| ① 招标明示 | `01c.typography.source == tender_required`（① 抽取规则保证：检出任一排版要求即标 `tender_required`；手改 01c 排版值时须同步 source，否则按基线档处理） | 逐项采用；单项空值回落基线并在 `sources` 记录 `baseline` |
| ② 甲方模板 | 命令行 `--template <docx>` 必传 | 纯标准库解析 docDefaults（字体/字号/行距/缩进）＋sectPr（页边距） |
| ③ 通用中文基线 | 招标未提出任何排版要求 | `assets/style-profiles/通用中文基线.yaml` |

- 三档**不取交集、不折中**：有明示用明示，无明示整体用基线。
- 任何档位下都必须产出《排版依据说明.md》：招标档逐项列来源；基线档明示「无招标要求，采用基线」。
- `bid_mode=blind` 时叠加暗标层（见 §三），叠加层与档位判定正交。

## 二、通用中文基线参数（内置允许整份替换，但不得进判定逻辑）

| 项 | 基线值 |
|---|---|
| 正文字体 | 仿宋_GB2312 |
| 正文字号 | 12pt（小四） |
| 行距 | 1.5 倍 |
| 首行缩进 | 2 字符 |
| 页边距 | 上下 2.54cm；左右 3.17cm |
| 页码 | 页脚居中 |
| 页数上限 | null（未载明时按隐含要求估算并写明依据，铁律 3） |

## 三、暗标叠加层（overlay，不是第四档）

与 `bid_mode=blind` 绑定，叠加于任一生效档位之上，**不改变字体/字号/行距等排版参数**，只做匿名化约束（四条规则详见 `assets/style-profiles/暗标叠加层.yaml`）：页眉页脚无单位名/标识、无 LOGO、清空作者类属性、正文无身份信息（检查项，报事实态）。普通标仅执行「清空作者类属性」一条。

## 四、编号与页码规则（导出侧执行口径）

1. **章名**：逐字取自 `01c_format-outline.json`（铁律 2），导出侧一个字不改；目录按 01c 顺序两遍法生成（页码第二遍回填收敛）。
2. **附件号**：`evidence/` 文件名前缀 `A-NN` 优先；无前缀按装配顺序自动补号；`03b_evidence-index.json` 的 `order` 与附件号必须自洽。
3. **页码**：docx 用页脚 PAGE 域（非写死数字）；合订 PDF 实测页数与 `pagination.json` 闭合（总页数＝正文〔含目录〕＋证据），目录页码与正文实际页一致。
4. **页数上限**：`01c.typography.page_limit`；超限 rc=1（铁律 3），不静默截断。
5. **页眉页脚**：普通标保留单位名（投标人身份合法展示）；暗标按 §三 叠加层第一条执行。

## 五、正文标注的处理（样式层不改内容）

- `[[EV:…]]` → 「见附件A-xx（第 N–M 页）」，页码取自 pagination.json（附件号与「（」之间不加空格）；
- `[[F:]]`/`[[S:]]` 溯源标注：交付稿剔除（不进正文），其核查归 ③ `check_facts.py`；
- 扫描件内容**不得**抄录进正文（铁律 1），只有附件引用。
