# bid-docx-export（④ 投标文件排版导出）

套件第 ④ 环，链路收口：**只改外观与装订，一个字的内容都不改**；未过 G5 拒绝导出。

## 输入

| 输入 | 说明 |
|---|---|
| `stage = recheck_confirmed` | 入口 stage |
| `05_chapters/*.md` | 正文定稿 |
| `01c_format-outline.json` | 章名（逐字）与排版参数 |
| `06_compliance/` | 至少含 `form-check.md`、`consistency-issues.md`（后者由 ②-B 阶段 2 产出，未到阶段缺失不按缺件拒） |
| `03b_evidence-index.json` | 扫描件索引 |

**G5 闸门**：`form-check.md` 有空项 → 阻断；②-A 结论中未解决的 `expired` → 阻断导出（④ 不重判时效，仅联动结论）。

## 产出

`07_out/{投标文件.docx, 投标文件_含附件.pdf, 排版依据说明.md}`

## 排版三档（不得颠倒）

① 招标明示（`01c.typography`）→ ② 甲方模板 → ③ 通用中文基线（**仿宋、正文小四、1.5 倍行距、首行缩进 2 字符**）。选档结果写入《排版依据说明.md》。

## 操作须知

- **另存后再编辑**：交付件为只读基准，改稿请另存副本，避免交付件与依据说明失配。
- 电子标平台上传前，人工核对页数与文件大小上限（平台差异大，脚本无法覆盖全部平台）。
