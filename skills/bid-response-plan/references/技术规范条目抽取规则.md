# 技术规范条目抽取规则（① 规则文件）

> 契约：`assets/spec-items.schema.json`（0.1）。被引用位置：① `SKILL.md` §三主流程第 2 步。
> 实现：`scripts/build_bid_plan.py` 的 `build_01b()`。

## 一、抽取对象

招标文件「技术标准和要求」章（本项目为 P2558+ 起）中**对投标设备/工艺有明确要求值**的条目：
风机、塔筒、基础、电气、吊装、施工、调试、试运行等全部技术要求。

## 二、`01b_spec-items.json` 结构

```json
{
  "schema_version": "0.1",
  "source": { "file": "…招标文件.docx", "page_range": "n/a-无分页（部分：…待全抽）" },
  "items": [ { "id": "sp-001", "clause": "前附表1.3.3", "page": "n/a-无分页",
               "requirement": "一次验收合格率", "required_value": "100%", "unit": "%",
               "tolerance": "", "no_negative_allowed": true, "raw_text": "…" } ]
}
```

| 字段 | 规则 |
|---|---|
| `id` | `sp-xxx` 稳定主键，排序变化不改 |
| `clause` | 章+条款号（如"前附表1.3.3""合同专用条款"） |
| `page` | 无分页文档（docx）填 `"n/a-无分页"`（保持非空）；PDF 填页码 |
| `requirement` | 要求项名称，照录 |
| `required_value` | 要求值，照录数值与单位 |
| `unit` | 单位；无单位填空串 |
| `tolerance` | 公差/允许偏差；未载明填空串，**不得自造** |
| `no_negative_allowed` | 不允许负偏离置 `true`；招标未明确置 `false`，**不得替招标加严** |
| `raw_text` | 原文摘录（保留引号与省略号） |

## 三、硬性规则

1. **只抄行，不判定偏离**：负偏离判定属 ③ 技术标/② 合规自检职责，① 只建条目；
2. **双校验（计划书 R3）**：抽取完成后做**行数比对 + 条款号比对**，与源章不一致即报错，
   不带着错继续往下走；
3. **完整抽取义务**：代表项先行时，必须在 `source.page_range` 注明"待全抽"范围，
   并进素材缺口清单；**不得把 2 条代表项当作全量交付**；
4. 合并行/跨行条目按"一条要求一条目"拆开，拆不出的照录整行并在 `raw_text` 保留原貌。

## 四、换项目适配

`FORMAT_CHAPTERS` 常量的换项目覆盖见《格式章与排版要求抽取规则》；`01b` 无项目常量，
每个项目从该项目的「技术标准和要求」章重新抽取。
