# 格式章与排版要求抽取规则（① 规则文件）

> 契约：`assets/format-outline.schema.json`（0.2，`01c` 与 `04` 共用）。
> 被引用位置：① `SKILL.md` §三主流程第 3 步。实现：`scripts/build_bid_plan.py` 的 `build_01c()`。

## 一、抽取对象（两处源）

1. **「投标文件格式」章**（格式章——在招标文件中的章序因项目而异，本项目为第七章）——章节树**逐字**抽取；
2. **前附表排版条款**——装订/签章/份数/递交方式（本项目为前附表 3.7.3/3.7.4/3.7.5）。

## 二、章节树规则

- 章名、编号、层级**逐字照抄**：不得改写、不得"美化"、不得合并拆分（铁律 2）；
- `level`：2=部（商务标/技术标/价格标），3=章，4=节；按源文档实际层级；
- `page`：无分页文档填 `"n/a-无分页"`；PDF 填页码；
- 章节 id 用稳定编码（`n-xxxx`），**排序变化不改 id**；
- **表格清单与章节树同源**：格式章载明的全部表格（表名、栏目/字段、签章位、顺序）**逐字照抽**，作为 ① `03c` 与 ③ 技术标响应表的唯一权威——**不得自造招标未载明的表格**（用户口径，2026-10-31；规则落点 `商务表格抽取规则.md` §三、`目录骨架规则.md` §四）。

## 三、排版要求（`typography`）

| 字段 | 口径 |
|---|---|
| `binding` | 照录前附表（如"A4胶装成册、不可拆卸；三册分开装订"） |
| `seal` | 照录前附表（电子CA签章/纸质签字盖章口径） |
| `page_limit` | 载明则填数值；**未载明填 `null` 并不得径断"无上限"**（铁律 3：按招标隐含要求估算并写明依据） |
| `font_body`/`size_body`/`line_spacing`/`margins`/`page_number` | **须并查格式章与前附表**（两处都读，任一载明即照录）；**非暗标项目同样抽取——不因非暗标而免抽**（用户口径，2026-10-31）；载明照录；未载明填空串（空值在 ④ 招标档 fail-loud 阻断，缺口溯 ⓪ 抽取层） |
| `identity_ban` | **暗标 8 项一对一映射**：投标人名称/标识/人员姓名/可识别信息等；**非暗标填空数组**（本项目全文 0 命中暗标要求 → `[]`） |
| `indent` | 未载明时给通用基线并注明"招标未载明" |
| `source` | `tender_required`（源自招标要求） |

## 四、暗标 8 项核对（逐项一对一，缺失即报）

1. 不得出现投标人名称、缩写、曾用名；
2. 不得出现标识/logo/图章图案；
3. 不得出现拟派人员姓名；
4. 不得出现可识别投标人的任何信息（地址、电话、特有业绩描述）；
5. 字体字号统一（如载明）；
6. 页眉页脚口径（如载明）；
7. 签字盖章方式（如载明"不得签字/仅指定位置盖章"）；
8. 封装/包封标识要求（如载明）。

> 任一项招标未载明 → 该项记"未载明"，**不得按"无要求"处理**。

## 五、换项目适配（重要）

`scripts/build_bid_plan.py` 的 `FORMAT_CHAPTERS` 常量**已固化本项目格式章结构**。
换项目时必须：

1. 重新抽取新项目「投标文件格式」章；
2. 覆盖 `FORMAT_CHAPTERS` 与 `TYPOGRAPHY` 两个常量；
3. 重跑 `build_bid_plan.py` 并核对 `01c.chapters` 与新项目格式章逐字一致。

## 六、表格权威与「不自创表格」禁令（用户口径，2026-10-31 固化）

- **唯一权威**：招标「投标文件格式」章列出的全部表格/函件（`03c` 商务表；技术标响应表同源）以格式章为唯一权威——**表名、栏目/字段、签章位、顺序一律逐字照抽**；
- **不得自造**：招标未载明的表格不得进入框架、任务卡或目录骨架（自造表＝偏离招标格式，格式废标优先于得分优化）；
- **资料缺口留白**：字段缺失时按格式章表形态留白（保留表头与栏目名、单元格留空），不写说明文字、不补造栏目；
- **换项目**：格式章重抽后表格清单随之重抽（不得沿用上一项目表名）；重跑后跑 `tests/validate_contract.py` C6（`03c` 不含金额）与 ① `scripts/validate_plan.py`。
