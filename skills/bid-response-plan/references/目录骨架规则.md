# 目录骨架规则（① 规则文件）

> 契约：`assets/format-outline.schema.json`（与 `01c` 共用 schema，版本 0.2）。
> 被引用位置：① `SKILL.md` §三主流程第 6/7 步。实现：`scripts/build_bid_plan.py` 的 `build_04()`。

## 一、章节顺序三源（优先级从高到低）

1. **`01c` 格式章章节树（逐字）**——第一来源，章名/编号/层级一律照抄，**不得改写、不得"美化"**（铁律 2）；
2. **评分项顺序**——仅决定同一章内内容块的编排参考；
3. **通用组织逻辑**——仅内容参考，**不得以此增删改招标规定的章节**。

> 铁律 2：格式废标优先于得分优化。**不得为凑评分点改章名**。

## 二、`04_outline.json` 结构

```json
{
  "schema_version": "0.2",
  "style_source": "招标文件第七章投标文件格式 + 前附表",
  "chapters": [ { "id": "n-1101", "number": "1", "title": "投标函格式",
                  "level": 3, "page": "n/a-无分页", "scoring_hits": ["S-01"] } ],
  "typography": { "…": "与 01c 共用同一 TYPOGRAPHY 常量" },
  "notes": "评分点落点仅供编排参考，不得为凑评分点改动章节名（铁律2）"
}
```

- `chapters[]` 与 `01c.chapters[] **逐条对应、同序同数**（目录骨架不得丢章）；
- `scoring_hits`：落入该章的任务卡 `source_ref`（`S-*`/`T*`），**只作标注**；
- `typography` 与 `01c_format-outline.json` **完全一致**（同一常量产出，防两处漂移）。

## 三、篇幅分配（主流程第 7 步）

- 按**分值权重**分配 `word_target`：分值 >10% 的评分项重点投入；
- 总页数受 `01c.typography.page_limit` 约束（铁律 3）：**正文 + 证据合计不得超限**；
  `page_limit` 未载明时**不得径断"无上限"**——按招标的隐含要求估算并**写明依据**；
- 核心参数可达性预判写入任务卡 `notes`（缺事实库的参数标注 `【待填】`，不预填）。

## 四、硬性禁止

- 不新增招标格式章之外的"自创章节"进骨架（补充材料进"招标文件要求提供的其他材料"位）；
- 不用通用模板目录覆盖本项目 01c（换项目必须重抽格式章，见《格式章与排版要求抽取规则》）；
- `scoring_hits` 为空是正常态（该章无评分落点），不得为填满而硬挂。
