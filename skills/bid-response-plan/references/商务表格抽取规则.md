# 商务表格抽取规则（① 规则文件）

> 契约：`assets/business-forms.schema.json`（0.1）。被引用位置：① `SKILL.md` §三主流程第 4 步。
> 实现：`scripts/build_bid_plan.py` 的 `build_03c()`。

## 一、抽取对象

第七章「投标文件格式」商务标部分列出的**全部表格与函件**（本项目 `bf-01`~`bf-24`），
外加价格标的报价表框架。技术标的表格不在此列（属 ③ 技术标范围）。

## 二、`03c_business-forms.json` 结构

```json
{
  "schema_version": "0.1",
  "forms": [ { "id": "bf-01", "name": "投标函", "tender_page": "n/a-无分页",
               "chapter_id": "n-1101",
               "required_fields": ["投标总报价（大写）", "…"],
               "seal": "法定代表人签字+单位公章",
               "copies": 5, "filled_file": "", "status": "blank" } ],
  "consistency_rules": [ "大写金额 = 小写金额", "…" ]
}
```

| 字段 | 规则 |
|---|---|
| `id` | `bf-xx` 稳定编号，与任务卡 `business` 类的 `source_ref` 一一对应 |
| `name` / `chapter_id` | 表名照录；`chapter_id` 必须解析到 01c 章节 |
| `tender_page` | 无分页文档填 `"n/a-无分页"` |
| `required_fields` | **只列字段名，不填任何值** |
| `seal` | 签章位照录前附表（签字/盖章/按 3.7.3 等） |
| `copies` | 份数（一正四副 → 5） |
| `filled_file` / `status` | 空串 / `blank`——填写发生在 ③ 成文阶段，① 不预填 |

## 三、硬性规则

1. **零金额**：框架**不得包含任何金额数字**（铁律 1：报价由人工填，AI 不预填不测算）；
2. **字段不造**：`required_fields` 只收招标格式表明示的字段；招标未列的表，按前附表
   通用要求列字段并在 `notes` 注明依据；
3. **一一对应**：每张表必须有对应 `business` 任务卡，反之亦然（②-A D 类检查此闭合）；
4. **一致性规则**（`consistency_rules`）至少含：大写金额=小写金额；各报价表分项合计=
   报价汇总表投标总价；投标保证金金额与前附表 3.4.1 载明一致。

## 四、与任务卡的衔接

`business` 类任务卡的 `source_ref` = `bf-xx`；`response_form` 按表性质取
`table`（表格）/ `letter`（函件）/ `scan`（证明件）；报价表一律 `table` 且
`status` 默认 `blocked_by_facts`（金额待人工/事实库）。
