## 使用须知

- **五要素齐全才可用**：最易漏的是「输入」和「约束」。不给输入，AI 只能凭通用知识硬撑，必然空洞；不给约束，字数风格全不可控。
- **角色/任务/约束可复用**，每次只换「输入」里的项目信息。
- **占位符 `{{ }}` 必须替换**：未提供的信息就写「未提供」或保留 `【待填：××】`，**不得让 AI 自行推测填充**（铁律 1）。
- **降级指令必须执行**：每条模板末尾【能力依赖：L2】标注了对应脚本；无脚本环境（L0）时按该处的人工走查要求执行，并在结论写明「人工走查，未经脚本机检」——不得跳过，也不得谎称已机检。
- **03 不得独立使用**：必须先有 `01c`（格式章章节树），章名逐字取自它，否则可能直接触发格式废标。
- **04 必须过 G4**：未提供已确认技术路线时，正文只输出到 `【待确认：技术路线】` 为止，禁止用通用做法填充（铁律 8）。
