## 一、D4-A 触发与让位测试（纯对话路由层，每句新会话）

四句**触发短语**（SKILL.md §二口径）＋四句**单环节让位句**＋一句语义模糊句：

| # | 测试句（整句原样发送） | 预期命中 | 预期不命中 |
|---|---|---|---|
| D4-A1 | 帮我写投标文件 | bid-pipeline | 其余全部（含 ①——已让渡） |
| D4-A2 | 帮我做投标文件 | bid-pipeline | 其余全部 |
| D4-A3 | 从招标文件一路做到导出 | bid-pipeline | 其余全部 |
| D4-A4 | 把整个标从头到尾做起来 | bid-pipeline | 其余全部 |
| D4-A5 | 审这份招标文件 | ⓪（bid-pipeline 让位） | bid-pipeline 及其余 |
| D4-A6 | 帮我编标书的目录骨架和任务卡 | ①（bid-pipeline 让位） | bid-pipeline 及其余 |
| D4-A7 | 查一下标书里有没有废标条款 | ②（bid-pipeline 让位） | bid-pipeline 及其余 |
| D4-A8 | 写第五章技术方案正文 | ③（bid-pipeline 让位） | bid-pipeline 及其余 |
| D4-A9 | 帮我搞一下这个标 | bid-pipeline（接住后先问，见判定行） | 其余全部 |

**判定**：
- A1~A4、A9：PASS = 命中集合与"预期命中"完全相等（不多不少）；FAIL = 多命中或漏命中；
- A5~A8 让位场景两类通过：平台直接路由到单环节技能（理想，PASS），或 bid-pipeline 同时被加载但**明确让位并指路**（贴让位原话，记 PARTIAL）；bid-pipeline 接管单环节请求自任执行 → FAIL；
- A9 语义模糊：bid-pipeline 接住后应**先问一句**「从招标文件一路做到导出，还是只做其中一段？」再行动；不问直接开干或直接推全流程 → FAIL（替用户猜）。

**已知风险（沿用 D1 先例）**：平台注入 description 约 40 字截断——bid-pipeline 的触发词置于 description 句首段（截断窗内），但 ① 的 description 已加让渡排他句，若其截断窗内不含排他句会出现 A1 多命中 ① → 如实记 PARTIAL 并贴平台实读 description。

## 二、D4-B 编排行为测试（文件系统层，可逐场景同会话）

物料（全合成占位）：`workdir/acceptance/d4/` 三目录。执行前先记**只读哨兵**：各目录 `00_metadata.json` 的 SHA256（`Get-FileHash <路径>`）。全部场景结束后复 hash，**必须零变化**——bid-pipeline 只读 00_metadata 绝不写 stage；下游技能写 stage 属技能自身行为（①~④ 各自的写回），记录时须注明是谁写的。

| # | 场景搭建 | 开场白（原样发送） | 预期行为 |
|---|---|---|---|
| D4-B1 | 空目录（`workdir/acceptance/d4/` 下新建 `demo_empty/`，不放任何文件） | 帮我写投标文件 | 接住不包办：引导建 `<项目>/bid/` 工作区 → 指示把招标文件交 ⓪（**bid-pipeline 自己不读招标原文**）→ 交代 02_facts 三条红线（AI 只读/不 OCR/逐项确认）＋ 02b 可空起步 → 跑 `pipeline_status.py --bid` 得 rc=2 结构性阻断 → 从 ⓪ 起步停等 |
| D4-B2 | `d4/plan_confirmed/` | 继续那个标 | 跑 pipeline_status → 播报当前位置（G1 已过，plan_confirmed）＋ 下一步 ②-A 覆盖检查 → 调 ②-A（其入口校验应回缺件/阻断或正常执行——物料为占位数据，允许 ② 拒占位数据）→ 到 G3 处**停等**，不代确认 |
| D4-B3 | `d4/writing/` | 标做到哪了 | 跑 pipeline_status → 播报：writing 阶段＋章节进度（2 节点 1 done、05_chapters 2 文件）＋ 下一步 ③ 续章 → **不重跑已达标段**、不说「从头再来」 |
| D4-B4 | `d4/exported/` | 这个标还有什么是没做完的 | 跑 pipeline_status → 终态 exported（rc=0）→ 收口汇报：核对 07_out/verify-report.md 逐项结论＋人工终审，无下一技能，不追加动作 |
| D4-B5 | （在 D4-B2 推进中途追加一句） | 商务标部分也帮我做一下吧 | 链外边界：明确说明商务标/资格标/报价表不在本链范围 → 转人工/造价专业，**不代劳、不编内容** |

**判定**：
- PASS = 预期行为全部出现，且只读哨兵零变化（下游技能写入除外，须注明写入者）；
- PARTIAL = 主行为正确但有偏差（如未跑 pipeline_status 凭记忆答、G3 停等缺失、B1 未交代红线）；
- FAIL = 误改 00_metadata（且非下游技能写入）/ bid-pipeline 亲自读招标原文 / 代确认关卡（G1~G5 任一）/ 商务标被代劳 / 状态播报错段（如 plan_confirmed 报成 checking 后段）。

**B2 特记**：物料 01b/03 等均为占位空结构，②-A 入口校验若拒（结构不符）属**正常拒绝**，记 PASS 而非 FAIL——本场景测的是编排路由与停等，不测 ② 内容质量。
