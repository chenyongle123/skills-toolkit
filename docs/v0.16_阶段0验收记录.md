## 四、未实测项与原因

1. **平台端到端触发（第 5、6 项的残余部分）**：四技能已装入并完成四轮静态判定，暴露并修复 2 处语义重叠（①+③、⓪+④）。**仍未做**的是真实端到端——用户在新会话发"帮我写投标文件"，观察实际加载的是否只有 ①。另发现**平台注入 description 时约 40 字截断**；若真实路由也只读截断部分，加在末尾的排他句可能失效。此风险已记入 `v0.16_触发实测记录.md` §五.2。

3. **两轨对账（第 8 项）**：需真实招标文件与完整七类清单，属阶段 1 联调范围。
4. **`facts.schema.yaml` 无语义校验**：无 PyYAML 环境下只做 hash 与人工审阅；②③ 解析时若格式错，会在运行期暴露。已作为已知限制记录。
